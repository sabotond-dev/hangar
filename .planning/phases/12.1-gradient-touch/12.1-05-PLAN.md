## `touch.ts`

```ts
import { sensorAt } from "../catalog/calibration";
/**
 * Canvas offset to the raw value the SENSOR reports for a finger at that point on the pad.
 * LED n is at u = n; the map is calibration.ts's forward map (measured on the user's ZONA, Probe C,
 * 2026-09-11) and saturates at the outer knots as the sensor does. The default axis keeps the two
 * existing call sites correct on x; their y lines gain "y" at 12.1-08.
 */
export function mapAxis(offset: number, extent: number, max: number, axis: "x" | "y" = "x"): number {
  if (extent <= 0) return 0;
  const u = (offset / extent) * 9 - 0.5;          // LED n at u = n
  return sensorAt(u, axis, max);                   // clamped into 0..max inside
}
```

The header's paragraph about "every ninth of the canvas lands on one LED column" is superseded and is
rewritten, not left.
