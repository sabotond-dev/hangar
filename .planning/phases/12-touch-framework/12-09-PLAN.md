and its own Timer watchdog releases a chord after twenty Timer calls. Single voice: `s.z` is the
sounding pad and `s.c` the contact holding it; a contact landing on a different pad releases the old
chord and sounds the new; `R=function(s,i)` releases the chord if `s.c==i` - and because `E` calls
`R` on an end code, on a stale press, **and** on the Timer's expiry, CHORUS's own watchdog is replaced
by `X(s,20)` in a Timer that shrinks from 174 to a few dozen characters. Twenty calls at `gtt(0,100)`
is two seconds, CHORUS's existing figure; the bench row in 12-12 decides whether it moves.

**MORPH, with the research corrected.** Two clauses are Setup arithmetic: 3x3 corners
(`self.k={0,6,54,60}`, `d%3+d//3*9` over `d=0,8`, +0) and a dead margin so a corner region reads a
full 127 / 0 (`x=glim((x-24)*127//79,0,127)`, same for `y`, +56). The third - "random lighting in the
centre" - is the trail cell flickering between neighbours under a wobbling finger, which is `Q`. **But
the research's call shape `if i>0 then return end local c=Q(s,i,e,x,y)if not c then return end` is
wrong for MORPH**: `Q` returns nil when the cell has not changed, and MORPH must recompute and send its
bilinear weights on every sample inside a cell or the card freezes between cells. MORPH keeps its own
end test, calls `Q` for the trail cell, sends weights regardless, and paints the trail only when `Q`
returned a cell. `D` is not used: MORPH's `@DECAY` reaches 126 and `D` covers 42.

research's 845 kept `s.q` for the mute row; try without it first and measure both.
