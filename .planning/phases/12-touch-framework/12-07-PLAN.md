<objective>
The framework, as a library in the system element, with the probe's constants.

**What the probe decided it must be** (`PROBE-RESULTS-2026-09-10.md`, "What the library must be"),
and **where each of the six rules lives** - because two of them are not the library's:

| Probe rule | Where it lives |
|---|---|
| 1. Cell hit-testing with hysteresis, margin 3 units (Q1, Q2) | **The library**: `W` and `Q`. |
| 2. A lift is never trusted on its own - a press clears a stale contact AND a Timer-side timeout releases a quiet one, **both**, because a stuck note is the worst failure a MIDI instrument has (Q6.5, Q7) | **The library**: `Q`'s two onset expiry clauses and `X`, all through `E` and the entry's `R`. |
| 3. Per-axis send-on-change, gated by cell or delta, **never on every sample** (Q1) | **The library**: `A`. Its caller in this phase is **LUMEN** (12-11), which today sends both axes unconditionally on every sample; 12-11 puts them behind `A`. It has **one** caller and the header says so. |
| 4. Single contact by default (Q6, Q6.5) | **Not the library.** The library tracks every contact - `H`, `T` and `P` are keyed by `i` - because CHORUS, CONSOLE, EUCLID and WHEELS all want per-contact tracking. The rule is an **entry-level** one, written `if i>0 then return end` in the cards that are single-pointer: MORPH and GHOST carry it today and GLIDE's sketch carries it. Each entry that takes it says so in its own header; the library does not impose it. WHEELS is the card that earns a two-finger bench row, which is the rule's own second sentence. |
| 5. The finger lights its cell | **Not the library, and no function ships for it.** The planner's sketch carried `F` for this and **nothing calls it**: the four cell-toggling sequencers decline it by name (12-08 - their armed cells toggle under the finger and that is the feedback), CONSOLE repaints through its own `P`, MORPH lights its trail, CHORUS its bloom, LUMEN its cursor cell, GLIDE its edges. Every card in this phase gives this feedback itself, so **`F` is dropped** and its characters return to the budget. If a later entry wants it, it comes back **with its caller named** - not on speculation. |
| 6. Nothing built on code 9 (Q3) | **The library**: the onset edge stays `(e==4 or e>8)` and `H[i]=e<9 and n` keeps the harmless handling; nothing depends on the `e>8` half. |

**What changed from the research's sketch.** The research costed `Q W A F D` at 643 with hysteresis
of +-9 raw units around the cell centre. The probe's margin is three, so the window is +-10 (`<11`).
The research had no expiry at all - it was a bench-blocked semantic - and the expiry is the largest
addition: a stamp table `T`, a Timer-driven counter `C`, an expiry function `E`, a Timer-side sweep
`X`, and a release convention `R` that an entry defines when it holds notes.

**Two planning figures, and only the second is the one to beat.** Measured under the pinned
`compressScript` during planning (a scratch script, deleted; nothing committed): the research's shape
plus expiry with a per-contact light layer cost **954** - over budget; with the light layer held once
in a global `L` it cost **885 of 908, 23 free**, syntax-checked by `GridScript.checkSyntax` and never
run in a VM. **That 885 sketch had two defects a plan-check found, so 885 is superseded and is quoted
here only as the figure this plan replaces:**

**Defect 1 - `Q`'s stale-contact rule could not fire for the same contact id, which is exactly the
probe's Q6.5 case.** The onset scan expired *other* contacts (`j~=i`) and never contact `i` itself.
Firmware assigns the lowest free id, so after a lost lift the next press is normally the **same id**.
Trace it: contact 0 presses cell 40; the lift is lost; contact 0 presses cell 40 again; `h = H[0] = 40`,
`n` is computed with hysteresis against the stale cell and is therefore 40, the scan skips `j==i`, and
`if n==h then return end` fires - **`Q` returns nil, the entry never sees the press, and that cell is
dead until the finger moves elsewhere.** The fix is one clause: **on an onset, expire contact `i`
itself before its cell is computed.** `h` is then nil, so the hysteresis cannot hold the stale cell;
the cross-contact scan no longer needs `j~=i` because `H[i]` is already gone; and an onset always
returns a cell. Test (b) below drives the **same-id** sequence, not only the cross-contact one.

**Defect 2 - `F` had no caller** (rule 5 above). It is dropped, and `O` and `L` go with it.

**The revised sketch is below, and its raw source length is 770** - a string length measured during
planning, **not a minifier measurement**, so it is a floor and not the cost.

**The delta is against the superseded sketch's RAW length, which was 884** (the minifier read **885**
on the same string, one longer, differing only in the joins - which is why the canonical fixed point
has to be taken before either number means anything). Part by part:
`Q` **+21** (the self-expiry clause, less the two savings it enables: `if o then` in place of
`if e==4 or e>8 then`, and the dropped ` and j~=i`), `E` **-4** (no `F(i)` call), the table header
**-7** (`O={}` and `L=1` gone), `F` **-123**, one join **-1**. That is **-114**, and
`884 - 114 = 770`. **Assert that arithmetic rather than copying 770**; if the parts do not sum, one of
them is mistyped.

**The executor measures the revised string under `compressScript` after `padReady()`, canonicalises
it, runs it in wasmoon, and records the measured cost beside the raw 770, beside the superseded 885,
and beside the free characters it leaves.** If the VM finds a semantic the sketch got wrong, the fix
is measured again.

**Where the risk in the expiry lives, and who decides it.** The firmware's change gate
(`grid_ui_touch_store_input:127-131`) drops repeats, so a finger that is *perfectly* still sends
nothing. Q1 shows a real finger wobbles every sample, but nothing guarantees it. A Timer window
shorter than the longest genuine hold would release a held chord. So the window is the caller's
argument in Timer calls (`X(s,n)`), not a library constant; CHORUS already carries a 20-call watchdog
at 100 ms (2 s) and keeps that figure; **the bench row in 12-12 asks the user to hold a chord still
for ten seconds and report whether it releases**, and that answer moves the callers, not the library.

**Q7's phantoms are not this library's to fix.** A large contact that loses its lift and keeps
*jittering and sending* is reported by the controller as live; no timeout can see it as quiet. That is
a hardware finding recorded for the production unit. What the expiry answers is Q6.5 - contacts that
went quiet without a 5.

## The sketch, six functions, raw source length 770 (planning, 2026-09-10) - to be measured, run and canonicalised

```lua
--[[@cb]]H={}T={}C=0 P={} function W(v,p)if p then local k=(p*128+64)//9 if v-k<11 and k-v<11 then return p end end return v*9//128 end function E(s,i)H[i]=nil T[i]=nil if R then R(s,i)end end function Q(s,i,e,x,y)if e~=1 and e~=4 and e<9 then E(s,i)return end local o=e==4 or e>8 if o then E(s,i)end T[i]=C local h=H[i]local n=W(x,h and h%9)+W(y,h and h//9)*9 if o then for j,g in pairs(H)do if g==n then E(s,j)end end end if n==h then return end H[i]=e<9 and n return n end function X(s,n)C=C+1 for i,t in pairs(T)do if C-t>n then E(s,i)end end end function A(s,i,e,x,y,c,d,h)local p=P[i]or{}if e<4 then if x~=p[1]then s:gms(h,176,c,x,0)end if y~=p[2]then s:gms(h,176,d,127-y,0)end end P[i]={x,y}end function D(n,l,w)local a=glag(0,n)glpfs(a,l,w,250,0)glt(a,l,w//6)end
```

| Name | Contract |
|---|---|
| `W(v,p)` | one-axis hysteresis: if the contact held cell `p` on this axis, keep it while `v` is within +-10 of `p`'s centre `(p*128+64)//9`; else `v*9//128`. A cell is ~14.2 units wide (half 7.1), so leaving the held cell needs 11 units from its centre against 7.1 naive - **an effective margin of ~3.9 raw units, stated as 4**, against the probe's "at least 2, 3 is the working figure". (The 885 sketch's table said 2.9; that was the `<10` window's figure and it is wrong for `<11`.) **On the probe's 71/72 boundary the band is seven values, 68..74**: centres are 64 (cell 4) and 78 (cell 5); from cell 4, x = 72, 73, 74 stay in 4 and 75 switches to 5; from cell 5, x = 68 stays in 5 and 67 switches back to 4. **Seven, not eight** - count them |
| `E(s,i)` | expire contact `i`: forget its cell and its stamp, and call `R(s,i)` if the entry defined one. It lights and darkens nothing, because no entry asked the library to |
| `Q(s,i,e,x,y)` | an end code (`e~=1 and e~=4 and e<9`) expires the contact and returns nil. Otherwise, **on an onset (`e==4 or e>8`), FIRST expire contact `i` itself** - a press by an id that still holds a cell means that id's lift was lost, and the hysteresis must not read the new press against the stale cell (this is Q6.5, and it is the case the same id normally takes, because firmware assigns the lowest free id). Then stamp `T[i]=C`, compute the cell with hysteresis on both axes, and **on an onset also expire any other contact holding the cell just landed on** (a press on a held cell means that holder is a ghost too) - the scan needs no `j~=i` guard because `H[i]` is already gone. Return the cell only when it changed; an onset therefore always returns one |
| `X(s,n)` | Timer-side: `C=C+1`, expire every contact whose stamp is older than `n` calls. **`n` is in Timer calls, chosen by the caller.** Callers in this phase: EUCLID, STEPS, RADAR POINTS and SONAR (12-08) and CHORUS (12-09) |
| `A(s,i,e,x,y,c,d,h)` | the user's own bench snippet, per contact: on live codes (`e<4`), send CC `c` = x when x moved and CC `d` = 127-y when y moved, on channel `h`; a DOWN primes `P[i]` without sending. **One caller: LUMEN (12-11)**, whose two `s:gms` calls are outside every gate today. The header says it has one caller, and names `127-y` as the snippet's own inversion so nobody reads it as a bug |
| `D(n,l,w)` | a decay landing on phase 0: `glpfs(a,l,w,250,0)` + `glt(a,l,w//6)`, rate 250 is -6 on the byte ring, so `w` a multiple of 6 lands exactly. **`w` is a byte, so `D` covers timeouts of at most 42 ticks**; an entry whose decay knob reaches beyond that (MORPH `@DECAY` runs 21..126) keeps the inline idiom `decay-idiom.spec.ts` gates. **One caller: GLIDE (12-10)** |
| `R` | **a convention, not a function the library defines**: an entry that holds notes sets `R=function(s,i) ... end` in its Setup, releasing whatever contact `i` held. `E` calls it on every expiry path - an end code, a same-id re-press, a stale-cell press, and the Timer sweep. **One caller: CHORUS (12-09)** |
