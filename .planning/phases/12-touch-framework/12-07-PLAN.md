<objective>
The framework, as a library in the system element, with the probe's constants.

**What the probe decided it must be** (`PROBE-RESULTS-2026-09-10.md`, "What the library must be"):
cell hit-testing with hysteresis at a margin of three units (Q1, Q2); a lift never trusted on its own -
a press on a stale cell clears it AND a Timer-side timeout releases a quiet contact, both, because a
stuck note is the worst failure a MIDI instrument has (Q6.5, Q7); per-axis send-on-change gated by cell
or delta, never per sample (Q1); single contact by default (Q6); the finger lights its cell; nothing
built on code 9 (Q3).

**What changed from the research's sketch, and what it cost.** The research costed `Q W A F D` at 643
with hysteresis of +-9 raw units around the cell centre (a finger travels about two units past a
boundary to switch). The probe's margin is three, so the window is +-10 (`<11`). The research had no
expiry at all - it was a bench-blocked semantic - and the expiry is the largest addition: a stamp table
`T`, a Timer-driven counter `C`, an expiry function `E`, a Timer-side sweep `X`, and a release
convention `R` that an entry defines when it holds notes. **Measured during planning under the pinned
`compressScript`** (a scratch script, deleted; nothing committed): the research's shape plus expiry
with a per-contact light layer costs **954** - over budget; with the light layer held once in a global
`L` it costs **885 of 908, 23 free**, syntax-checked by `GridScript.checkSyntax`, **not yet run in a
VM**. That sketch is below. The executor runs it in wasmoon before a header claims a number, and if
the VM finds a semantic the sketch got wrong, the fix is measured again.

**Where the risk in the expiry lives, and who decides it.** The firmware's change gate
(`grid_ui_touch_store_input:127-131`) drops repeats, so a finger that is *perfectly* still sends
nothing. Q1 shows a real finger wobbles every sample, but nothing guarantees it. A Timer window
shorter than the longest genuine hold would release a held chord. So the window is the caller's
argument in Timer calls (`X(s,n)`), not a library constant; CHORUS already carries a 20-call watchdog
at 100 ms (2 s) and keeps that figure; **the bench row in 12-12 asks the user to hold a chord still
for ten seconds and report whether it releases**, and that answer moves the callers, not the library.

**Q7's phantoms are not this library's to fix.** A large contact that loses its lift and keeps
*jittering and sending* is reported by the controller as live; no timeout can see it as quiet. That is
a hardware finding recorded for the production unit. What the expiry answers is Q6.5 - contacts that
went quiet without a 5.

Purpose: one library, one cost, one wire shape, gated the way Phase 11 gated its idioms.
Output: two files created, five edited, eight tests added, and every hand-authored entry able to call
`Q` from the next plan on.

## The sketch, measured at 885 under the pin (planning, 2026-09-10), syntax true, not yet run

```lua
--[[@cb]]H={}T={}C=0 O={}P={}L=1 function W(v,p)if p then local k=(p*128+64)//9 if v-k<11 and k-v<11 then return p end end return v*9//128 end function E(s,i)H[i]=nil T[i]=nil F(i)if R then R(s,i)end end function Q(s,i,e,x,y)if e~=1 and e~=4 and e<9 then E(s,i)return end T[i]=C local h=H[i]local n=W(x,h and h%9)+W(y,h and h//9)*9 if e==4 or e>8 then for j,g in pairs(H)do if g==n and j~=i then E(s,j)end end end if n==h then return end H[i]=e<9 and n return n end function X(s,n)C=C+1 for i,t in pairs(T)do if C-t>n then E(s,i)end end end function A(s,i,e,x,y,c,d,h)local p=P[i]or{}if e<4 then if x~=p[1]then s:gms(h,176,c,x,0)end if y~=p[2]then s:gms(h,176,d,127-y,0)end end P[i]={x,y}end function F(i,n,l)L=l or L local o=O[i]if o and o~=n then glp(glag(0,o),L,0)end if n then glp(glag(0,n),L,255)end O[i]=n end function D(n,l,w)local a=glag(0,n)glpfs(a,l,w,250,0)glt(a,l,w//6)end
```

Per part, measured: header 9 · tables 23 · `W` 109 · `E` 60 · `Q` 261 · `X` 74 · `A` 150 · `F` 123
· `D` 68. The whole string joined with single spaces measured **885**; `compressScript` of the whole
returned a string of the same length that differed only in the joins - **make it canonical** (run the

| Name | Contract |
|---|---|
| `W(v,p)` | one-axis hysteresis: if the contact held cell `p` on this axis, keep it while `v` is within +-10 of `p`'s centre `(p*128+64)//9`; else `v*9//128`. A cell is ~14.2 units wide (half 7.1), so a finger travels ~2.9 units past a boundary to switch. **On the probe's 71/72 boundary: from cell 4, x = 72, 73, 74 stay in 4 and 75 switches to 5; from cell 5, x = 68 stays and 67 switches back - an eight-unit band** |
| `E(s,i)` | expire contact `i`: forget its cell and stamp, unlight via `F(i)`, call `R(s,i)` if the entry defined one |
| `Q(s,i,e,x,y)` | an end code (`e~=1 and e~=4 and e<9`) expires the contact and returns nil; otherwise stamp `T[i]=C`, compute the cell with hysteresis on both axes, **on an onset expire any other contact holding that cell** (a press on a held cell means the holder is a ghost), and return the cell only when it changed (or on onset) |
| `X(s,n)` | Timer-side: `C=C+1`, expire every contact whose stamp is older than `n` calls. **`n` is in Timer calls, chosen by the caller** |
| `A(s,i,e,x,y,c,d,h)` | the user's snippet per contact: on live codes (`e<4`), send CC `c` = x when x moved and CC `d` = 127-y when y moved, channel `h`; a DOWN primes without sending |
| `F(i,n,l)` | the finger lights its cell on layer `l` (remembered in `L`); the previous cell goes dark; `F(i)` darkens and forgets |
| `D(n,l,w)` | a decay landing on phase 0: `glpfs(a,l,w,250,0)` + `glt(a,l,w//6)`, rate 250 is -6 on the byte ring, so `w` a multiple of 6 lands exactly. **`w` is a byte, so `D` covers timeouts of at most 42 ticks**; an entry whose decay knob reaches beyond that (MORPH `@DECAY` runs 21..126) keeps the inline idiom `decay-idiom.spec.ts` gates |
| `R` | **a convention, not a function the library defines**: an entry that holds notes sets `R=function(s,i) ... end` in its Setup, releasing whatever contact `i` held. `E` calls it on every expiry path |

## The host (`lua-host.ts`)

```
today   install(): registerGlobals -> SELF_PRELUDE -> timer wrapper -> PRISTINE_SNAPSHOT -> Setup -> TOUCH_DISPATCH
after   install(): registerGlobals -> SELF_PRELUDE -> timer wrapper -> PRISTINE_SNAPSHOT -> doString(system) -> Setup -> TOUCH_DISPATCH
today   restart(): RESTART_WIPE -> SELF_PRELUDE -> Setup -> TOUCH_DISPATCH
after   restart(): RESTART_WIPE -> doStringSync(system) -> SELF_PRELUDE -> Setup -> TOUCH_DISPATCH
```

`system` runs **after** the pristine snapshot so `H T C O P L` and the seven functions are wiped by
`RESTART_WIPE` and rebuilt - Pitfall 3: a remounted card must not inherit `H[i]` from the last one.
`LuaHostOptions.system?: string`; `setupSource`'s twin `systemSource` kept for restart. The library
uses `glp glag glpfs glt s:gms math.abs` - all registered; **no new host global**.

Callers that build a host by hand: `lua-smoke.spec.ts:121, 432 (open()), 572, 3407, 3660, 4825` -
`open()` passes `system: TOUCH_LIBRARY`; the other five are read and either pass it or are proved not
to need it (a preset-backed host does not). `createLuaPadSim` (`lua-pad-sim.ts:208-218`) passes it for
every lua entry; presets never see it.
