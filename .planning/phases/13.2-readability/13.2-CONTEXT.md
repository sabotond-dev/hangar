## D-21 [planner] The built CSS is a function of comment vocabulary; the gate's CSS term is scoped

`src/app.css:1` is `@import "tailwindcss" source(".")`: Tailwind v4's scanner reads every file under
`src/` — `.ts`, `.svelte`, `.spec.ts`, comments included — and emits a utility for every token that
spells one (13.2-PLAN-CHECK H-1, measured on the build on disk: the `@layer utilities` block holds 45
classes, 5 named by a `class` attribute in markup — `block grid outline ring sr-only` — and 40 that
exist only because a word sits in a comment or a spec: `.row-0` from `calibration.ts:31`, `.ring-4` from
`lua-smoke.spec.ts:6035`, `.ordinal` from `sandbox/copy.ts:183` and `FacetRow.svelte:48` …; the 49
`@property` rules in `@layer properties` follow the same set). The research's "a comment inside
`<style>` does not move the CSS" is true of `<style>` blocks and of `app.css`, and false of every
other comment in the tree: cutting them moves `cat *.css | sha256sum`, and this phase cuts thousands.

So the gate's CSS term is **`scripts/gate/css-terms.mjs`**: the built stylesheets with the `@layer
properties{…}` and `@layer utilities{…}` blocks removed brace-balanced, hashed — **the scoped hash,
equal after every plan** (it still carries every `.svelte-<hash>` class, so a `.svelte` rename still
moves it; Svelte 5.57 hashes the filename); beside it the utilities layer's sorted class list is
recorded, every class a `class="…"` / `class:` / `@apply` token in `src/**/*.svelte` or `src/app.html`
names is asserted still emitted, and every class that appears or disappears is printed by name. A
class no template names cannot change what a visitor sees; one a template names must not go. The raw
hash is still recorded for the reader and is expected to move. The alternative — `source(none)` with
`@source "./**/*.svelte"` and `@source "./app.html"` in `app.css`, which would stop comments emitting
rules at all — is a real improvement and a visible one-time CSS delta, the kind of change the user
excluded; it is filed as a question, not folded into 01. **The rule that follows, written into
`docs/CODE-STYLE.md` by 13.2-01: a comment must not introduce a word shaped like a Tailwind utility**
(13-01's lesson, `app.css:3-21`: `rounded-md` in a planning document put a corner in the production
stylesheet, and `@source not inline(…)` refuses that one family by name); the gate prints every
utility that appears, and a comment that adds one is reworded.
