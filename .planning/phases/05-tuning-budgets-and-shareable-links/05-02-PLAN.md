<interfaces>
**The design contract is `05-UI-SPEC.md` and it is binding.** Cite it by section, never by line
number — it is under a final checker pass and line numbers will move. The sections this plan
implements are: *The knob vocabulary* (three widgets, twelve kinds, the fall-through), *Readouts*,
*Word tables*, *The two meters* (including *Percentage* and *The four meter states*), and the whole
*Copywriting Contract* table.

**The twelve kinds**, from `src/lib/catalog/types.ts`'s `KNOB_KINDS` and the vendored
`KnobKind` union: `colour`, `speed`, `direction`, `size`, `count`, `note`, `feel`, `amount`, `mode`,
`bend`, `spring`, `scale`.

**The widget rules**, from the UI spec:

| Widget | Kinds | Condition |
|---|---|---|
| swatch row | `colour` | every value parses as three integers in 0..255 |
| word row | `direction`, `mode`, `bend`, `spring`, `scale`, `note` | every value resolves to a word through the kind's table, **and** `n <= 8` |
| rail | `speed`, `size`, `count`, `feel`, `amount`, and everything that falls through | always available. `n <= 8` dot rail, `n >= 9` detent track |

The fall-through is total and deliberate: a `colour` whose values are not RGB, a `scale` whose
semitone set is not in the table, a `note` with more than 8 options and every unnamed kind all render
as a rail.

**A knob value is a Lua literal** — `"0,200,255"`, `"3,5,7"`, `"0,2,4,5,7,9,11"`, `"110"`. Those
strings are never shown to a visitor. `note` shows a pitch name, `scale` shows a mode name, a rail
whose every value is a single integer shows that integer verbatim (a MIDI channel whose literal is
`0` displays `0` — X-08), and everything else shows nothing.

**Percentage**: `floor(used / 908 * 100)` while `used <= 908`, `ceil(...)` while `used > 908`. So 907
reads 99, 908 reads 100, 909 reads 101, 941 reads 104.

**Swatch accessible names** are a hue word plus a position — `Cyan, 1 of 5`. Twelve 30-degree hue
buckets (Red, Orange, Amber, Lime, Green, Spring green, Cyan, Azure, Blue, Violet, Magenta, Rose)
with three neutrals below 10% saturation: White above 80% lightness, Grey above 20%, otherwise Black.
The five values shipped today are `0,200,255` → Cyan, `255,90,0` → Orange, `0,255,120` → Spring
green, `255,255,255` → White, `120,0,255` → Violet.

**Safari has no `requestIdleCallback`.** MDN records it as not Baseline; WebKit ships it behind a
feature flag only.
