<objective>
Build the four small components that carry the phase's whole story: two numbers, two messages, one
button.

Wave 9. The meters are where the design effort belongs, because they are the only part of this phase
a visitor can actually reach. Over budget is unreachable in practice; `tpad` at 902/908 and `dial` at
646/908 are genuinely different stories and the meters are what tell them.

Four rules from the UI spec shape these components and none of them is decoration:

- **Only a meter's two numeric columns are monospaced.** The caption stays Quicksand 600. Tabular
  numerals are mandatory on every changing number: a budget that jitters horizontally as it counts is
  the exact failure `--font-mono` was introduced for in Phase 4.
- **Staleness is an alpha change on the last-known numbers, not the `measuring…` word.** During a drag
  the debounce fires several times a second; swapping numerals for a word and back would strobe. The
  word is reserved for the very first measurement, when there is genuinely nothing to show. And
  staleness **never** applies while over budget, because dimming a warning is wrong.
- **The meters carry no ARIA role at all.** DEGR-01 requires iOS Safari, where VoiceOver's support for
  `role="meter"` is partial and inconsistent. Real text plus a visually-hidden expansion is understood
  by every AT on every platform and cannot regress. The bar is decoration.
- **`COPY LINK` must not `await` before it copies.** Safari expires the transient user activation
  across an `await` and the write then rejects with `NotAllowedError` — on the one browser family
  DEGR-01 exists for. The URL is precomputed on every knob change; the handler calls `writeText` and
  attaches `.then`.

Purpose: the four leaf components, each obeying its contract exactly.
Output: four components; the suite totals do not move.

**Say the sampling gap out loud, because this plan's delta is zero and that is unusual.** No
`.svelte.spec.ts` may exist in this repository, so nothing here is proven by a test written in this
plan: `npm run check`, `npm run lint` and the standing `config-shape.spec.ts` guards are the whole of

three waves between writing and observing, it is accepted deliberately rather than overlooked, and it
is why every acceptance criterion below is a source-level scan: a scan that runs today is worth more
than a promise that something will be checked on Friday.

<interfaces>
**`05-UI-SPEC.md` is binding.** Sections implemented here: *The two meters* (including *Percentage*,
*The four meter states*, *The formatter never loads at all*, *Timer of length zero*), *The fit-ladder
line*, *The over-budget state* parts 1 and 2, *`COPY LINK`* including the fallback, *The stamp and
the three landings*, and the Accessibility Contract rows about the meters and the live region.

**One meter is 26px** and the block is exactly 56px — `(14 + 4 + 8) x 2 + 4`. The row is
`display: grid; grid-template-columns: auto 1fr 40px; column-gap: 12px; align-items: baseline`, and
**all three cells carry `line-height: 14px`** (the region's fixed line box), which is exactly what
makes the row 14 and the block 56 rather than 14.4 and 56.8.

**The four meter states**:

| State | Numerals | Bar | ARIA |
|---|---|---|---|
| measuring | the word `measuring…` in `--font-mono` `--color-ink-quiet`; the percentage column empty | track only | `aria-busy="true"` |
| settled | `702 / 908` and `77%` in `--color-ink` | lime fill | — |
| stale | the *same last-known numbers*, dropped to `--color-ink-quiet` over 100 ms linear | fill unchanged | `aria-busy="true"` |
| over | `941 / 908` and `104%` in `--color-over` | 100% fill in `--color-over`, plus `outline: 2px solid var(--color-over); outline-offset: 2px` on the track | see the live region |

The visible `702 / 908` is `aria-hidden` and paired with a visually-hidden expansion:
`Setup uses 702 of 908 characters, 77 per cent.` — and for an empty event,
`Timer uses 0 of 908 characters. This configuration has no timer.` MORPH ships an empty Timer, so the
zero reading is a true measurement rather than a dead meter.

**Colour is never the only channel.** Over budget carries six independent signals: the red, the
outlined and completely full bar, numerals above 908, a percentage above 100, a disabled primary
control with a written reason, and a sentence naming the knob. WCAG 1.4.1 is satisfied with the red
removed entirely — that is the test that makes introducing it safe, and it is worth checking by
temporarily deleting the token's use.

**The over-budget block** lives in message slot B with a 2px `--color-over` left rule: one line naming
the knob, then `TURN IT DOWN` (Phase 4's secondary button treatment, 44px, one click, no
confirmation), then one quiet line saying exactly what the click will do and what the meter will read
afterwards. The label is `TURN IT DOWN` and deliberately **not** `PUT IT BACK` — Phase 7 owns
`PUT BACK` for restoring a module's own configuration, and two near-identical labels a phase apart on
one panel would be a genuine hazard on hardware people paid for.

**Message slot B is `auto` height and moves only inert content**; its transition is **opacity only,
never height**, 160 ms linear, instant under reduced motion.

**`COPY LINK`** sits below the hairline sharing a row with `KEEP ON DEVICE`. Its states: rest, hover
(border to accent, 140 ms), **confirmed** (`LINK COPIED`, accent border, 2000 ms, then back), and
fallback. The confirmation is the control's own state — no toast, no icon, no colour fill — and the
button's accessible name is always its visible text.

**The fallback** (no `navigator.clipboard`, or a rejected write): reveal a `readonly` `<input>`
directly beneath it containing the full URL, already `select()`ed, with one Body line above it. The
field is `--font-mono` **16px** — the iOS zoom floor, because iOS Safari zooms the viewport when a
field smaller than 16px takes focus — `min-block-size: 44px`, full width,
`aria-label="Shareable link"`. The button's label stays `COPY LINK`; the instruction lives in the
line, and it names keys rather than controls.

**Message slot A** carries `role="status"` so it is announced after hydration without a container that
was already live at first render, and it **disappears on the first knob change or on `RESET ALL`** —
it describes how the panel arrived, and once the visitor has taken over it is no longer true.

  <action>
Create `src/lib/ui/CopyLink.svelte`. One prop: `url: string` — **already composed**, never computed
here, and never awaited.

The handler is the whole point of the component:

```ts
function copy(): void {
  // No await before this call. Safari expires the transient user activation
  // across an await and writeText then rejects with NotAllowedError - on the
  // one browser family DEGR-01 exists for. The URL is precomputed on every knob
  // change for exactly this reason (05-RESEARCH, COPY LINK).
  navigator.clipboard?.writeText(url).then(confirmed, fellBack) ?? fellBack();
}
```

States: rest, hover (border to `--color-accent`, 140 ms), confirmed (`LINK COPIED`, accent border,
**2000 ms**, then back to rest), fallback (until the panel closes). The confirmation is the control's
own state — no toast, no icon, no fill. The button's accessible name is always its visible text, and
the copy is additionally announced once through the region's shared live region, which the region
owns and this component signals through a callback.

The fallback reveals a `readonly` `<input>` beneath the button holding the full URL, `select()`ed on
reveal, with one Body line above it. `--font-mono` at **16px** — the iOS zoom floor — `--color-ink`,
`1px solid var(--color-line)`, radius 2px, `min-block-size: 44px`, full width,
`aria-label="Shareable link"`, `data-testid="copy-link-fallback"`. The button's label stays
`COPY LINK`; the instruction lives in the line and it names keys, not controls.
`document.execCommand("copy")` is deprecated and is not the primary path; if it is used at all it sits
behind a capability check and is three lines.

`data-testid="copy-link"` on the button. Every string comes from `copy.ts`.

Phase 4's rule that "the two install controls are never the same size, never the same fill, never
adjacent" is untouched: `COPY LINK` is not an install control and never claims to be. It sits beside
`KEEP ON DEVICE`, which is disabled throughout this phase with a dim label and its own reason, while
