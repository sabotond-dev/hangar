Deliver the point of the front door: choose the centre pad and `TRY ON DEVICE` appears — a control
that really opens a port, really identifies a ZONA, and really cannot write to it.

so what ships here is the degrade path proven in a browser, the never-writes invariant proven in node
by plan 04-04, and a one-line human check for the user with a ZONA on the desk.

  in front of it.** Transient activation expires (about 4.9 s in current engines) rather than being
  consumed, so an awaited dynamic import ahead of it makes the picker reject with what reads as a
  permissions bug. Every module the handler needs is loaded in `onMount`.
  `src/routes/dev/skeleton/+page.svelte`'s `connect()` is the proven shape — copy it.

**Choosing and un-choosing** (D-11, D-09, UI-SPEC §Choosing and §Screen 3):

- Enter, Space, a click on the name-plate name, or a qualifying tap on the hero all choose.
- The tap rule, because play and choose share one gesture: a `pointerdown` on the hero **always**
  delivers a touch to the simulator; if the matching `pointerup` arrives within **250 ms** and the
  pointer moved less than **6 px**, it is *also* a choose. Anything longer or further is play only.
- Choosing calls `pushState("", { chosen: true })` from `$app/navigation`, so the browser Back button
  un-chooses and is the same gesture as `Escape`. The empty first argument is explicitly permitted by
  `svelte/no-navigation-without-resolve` for shallow navigation, so no lint disable is needed and none
  may be added. Read the flag back through `page.state` from `$app/state`.
- Un-choose on `Escape`, on Back, on a click on any dimmed side pad, and on stepping past the chosen
  entry.
- While chosen: side slots go to `opacity × 0.55` and `brightness × 0.8`, the whole band translates
  `-24px`, over 260 ms; the hero itself is **unchanged** — it stays the largest thing on screen.
- Stepping while chosen re-fills the panel with the new entry but does **not** reset the connect

async function tryOnDevice(): Promise<void> {
  const picked = await navigator.serial
    .requestPort({ filters: [P.ZONA_USB] })
    .catch((err: unknown) => { refuse(err); return undefined; });
  if (!picked) return;
  state = "opening";
  try {
    await picked.open({ baudRate: P.BAUD_RATE, bufferSize: P.READ_BUFFER_SIZE });
  } catch (err) {
    refuse(err, picked);
    return;
  }
  const grid = new T.WebSerialTransport(picked);
  detachHide = grid.closeOnHide();
  grid.onClose(() => { if (state === "identified") state = "unplugged-after"; });

  const result = await D.identifyOnly(grid);

}
