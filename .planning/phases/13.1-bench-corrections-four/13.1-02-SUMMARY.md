## `switchPage`, as shipped

```ts
async switchPage(page: number): Promise<boolean> {
  if (!this.requestPage(page)) return false;
  await this.confirmPage();
  if (this.pageStatus !== "switching") {
    this.cancelPage();
    return false;
  }
  return true;
}
```

The return is the wire's fact: TRUE exactly when the switch left (the target is `switching` after the
await), FALSE with nothing sent otherwise - when `requestPage` refused (a switch pending, no report
yet, a leg in flight or `writing`, the module's own page, no session) or when `confirmPage` returned
without sending, in which case `cancelPage()` takes the target back before the false (13.1-PLAN-CHECK
W-04). `requestPage`, `cancelPage` and `confirmPage` stay (the probe uses them; `cancelPage` is
`unverified`'s programmatic way out). `confirmPage` is still the one caller of `target.confirm(`
(`occurrences === 1`, asserted in the inverted test).
