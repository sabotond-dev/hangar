### The e2e hygiene, before and after

```
$ netstat -ano | grep -w LISTENING | grep ":4173"      # before: no output, exit 1
$ netstat -ano | grep -w LISTENING | grep ":4173"      # after:  no output, exit 1
$ tasklist | grep -iE "workerd|wrangler"               # after:  no output, exit 1
```

Nothing was listening on 4173 before the run, so no stale `wrangler dev` was reused and no
`taskkill` walk was needed. Playwright started its own `npm run preview` (build + `wrangler dev`) and
tore the whole tree down on exit: after the run there is no listener on 4173 and no `workerd.exe` or
`wrangler` process at all. Output was captured to `.tmp-e2e/baseline-05.1-01.txt` (gitignored).

**Both Playwright browsers are present, proven by use rather than by `--dry-run`:** the run reported
`44 passed` across both projects, and the tail of the log shows titles executing under `[chromium]`
and `[webkit-phone]` in the same run — for example
`ok 41 [webkit-phone] > e2e\tuning-webkit.e2e.ts:475:3 ... a shared link lands with the knobs restored`.
A missing browser binary fails the project outright, so 44 across two projects is the stronger
observation.
