<objective>
Three total orders, one folded search, one tag intersection and the keyboard arithmetic — four pure
modules under `src/lib/browse/`, tested in node with no DOM.

Wave 2. This is the whole of CAT-02's automated coverage and it exists as pure functions for the
reason `src/lib/coverflow/slots.ts` does: **this repository collects no `.svelte.spec.ts` in any
Vitest project**, so arithmetic written inside a component is untested and *looks* tested.

**The one decision a reader will want to check, so it is stated first.** `05.1-CONTEXT.md`'s D-10 was
amended after research, and the amendment is binding:

> sorts follow the shipped comparators in `src/lib/catalog/index.ts` — Featured is featured-first then
> Name (`byFeatured`), Name uses the codebase's deterministic comparator (its own comment forbids
> `localeCompare`), Newest is `addedAt` descending with Name as the explicit tiebreak. No sort may be
> unstable.

So: **no `localeCompare`, no `Intl.Collator`, and Featured breaks ties by name and not by date.**

**The approved UI spec agrees; the research does not.** `05.1-UI-SPEC.md` was approved on 2026-09-04
and its W-08 already reads *"Name sort is the shipped `nameAsc` — a plain code-point comparison — and
`FEATURED` is featured-first then name, with no `addedAt` tie-break"*, and its sort table at
§ The sort control names `byFeatured()`, `byNewest()` and `nameAsc` as the contract. **Nothing in the
UI spec is superseded by this plan.** What *is* superseded is `05.1-RESEARCH.md`: its Standard Stack
row for `Intl.Collator("en", { sensitivity: "base", numeric: true })` and its §Don't Hand-Roll row
recommending the same are **both overtaken by the D-10 amendment**, and `sort.ts`'s header says so by
file and by section, because otherwise somebody reading the research will "fix" the module to match
it.

**`nameAsc` is not exported from `src/lib/catalog/index.ts`** — it is a module-private function — so
the browse module **restates** it over `ListingEntry` rather than importing it, and the restatement is
**gated against the shipped comparators' output**: `byFeatured()`, `byNewest()` and `byName()` id
sequences, compared element for element. That gate is the only thing standing between a restated
comparator and a silent divergence, and it is why tests 2, 3 and 4 exist.

The consequence is worth writing into the SUMMARY: a code-point comparator sorts every all-caps name
ahead of every mixed-case one, so `NAME` reads `ARC, CHORUS, EUCLID, GHOST, LATTICE, MORPH, SONAR,
Aurora, Dial, …`. That is the shipped catalog's own order today and it is deterministic on every
machine, which is the property D-10 as amended chose.

copy needs.

**`src/lib/browse/grid.ts` and `grid.spec.ts`, exactly six tests**, one per behaviour above.

Three rules worth a comment:

- **Clamping, not wrapping.** `Coverflow` wraps because it is a ring; a grid is not, and ArrowDown
  from the last row landing on the first card is disorienting. This is the ARIA APG behaviour.
- **`undefined` for an unhandled key**, so the component never calls `preventDefault` on a key it did
  not act on — which is what keeps `Space` scrolling the page and `Alt+Left` meaning Back.
- **`columnsFromTemplate` clamps with `Math.max(1, …)`, explicitly.** `"none"` and the empty string
