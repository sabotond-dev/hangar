### `gks`, exactly

`gks(default_delay_ms, is_modifier, state, keycode, ...)`, rejected unless `(nargs - 1) % 3 == 0`.
`is_modifier` is 0 for an ordinary key, 1 for a modifier, **15 for a delay tuple**. `state` is 0 up,
1 down, **2 down-then-up**. `keycode` is a USB HID usage id, 0..255. It costs `10 + 4n` bytes of the
256-byte per-cycle protocol buffer.

**Every usage id shipped in this wave must be verified against a published HID usage table**, and the
table named in the SUMMARY. A wrong usage id presses the wrong key on somebody's machine and no gate
in this repository catches it.

### The seven traps

`glag(0, x + y*9)` always. Every division `//`; every `math.*` result closed with `// 1`. Colour
channels truncate rather than clamp. Onset is `e == 4 or e > 8`, an end is `e >= 5`, code 9 is a tap
with no separate lift. Never `glp(n,l,-1)`. Never a 65535 keeper on a decaying layer. No token may be
a prefix of another.

One layer caps at 49.6 % of the colour asked for; paint both for brightness. Layer 0 is never written.
Firmware advances armed phases in C for up to 655 s, then zeroes the rate.

### The copy rules (09-02's gate enforces every one)

One sentence, second person, present tense, active voice, naming the payoff. At most 110 characters,
one line, distinct. No exclamation mark, no emoji, no ASCII apostrophe between letters, no hyphen as a
dash, no ellipsis in a description. Four feel tags, each in `KNOWN_TAGS` or added on purpose. A single
upper-case word for the name. No **aurora**, no **ghost**.

### The knob rule

No sixteen-value channel knob. At most four: `"0"`, `"1"`, `"9"`, `"15"`. None of the three entries
here sends MIDI at all, so none needs a channel knob - and that is a saving worth taking.

### FORGE

**The card.** Editor and terminal macros in colour families, with a second bank under a held corner.

**Route: `lua`.** A per-cell colour map plus a modal second bank. `gridColour` is one colour for every
zone and there is no modal state in `PadState` at all.

**Mechanism.**

- Three horizontal bands of three rows each, one per macro family - say build, test and source
  control - painted in `@FAMA`, `@FAMB` and `@FAMC`, layer 2 dim and layer 1 off. `restsBlack: false`.
- Twenty-seven cells, one macro each: `gks(@DELAY, 1, 1, @MOD, 0, 2, @KEY0 + n, 1, 0, @MOD)` where `n`
  is the cell index within the bank. **`@KEY0 + 26 < 256`** for every `@KEY0` value; write the
  arithmetic into the header.
- **The bank.** Holding the bottom-right cell (index 80) switches to bank B: `self.b = 1` on its
  onset, `self.b = 0` on its end. Bank B shifts every keycode by `@BANK` and repaints the whole pad
  in a shifted hue so the change is unmistakable. **One repaint per bank change, never per press** -
  the touch-budget rule.
- **The modal hazard, and it must be handled rather than noted.** A held corner is a latch in
  everything but name, and firmware's dropped-release bug can leave `self.b` stuck at 1 - the module
  would then be in bank B forever with no way back. Two mitigations, both cheap, both required:
  (a) release the bank on **any** end event for the corner's contact id, not only on a lift of the
  corner cell; and (b) a Timer that clears `self.b` if no sample has arrived for `@HOLDMS`
  milliseconds - the slow watchdog `ZONA-CAPABILITIES.md` section 6 point 5 prescribes. The Timer
  therefore exists and is not `""`. Write both mitigations into the header, marked do-not-remove, with
  the bug they answer.
- Code 9 on the corner is a press-and-lift in one message: it must **not** leave the bank latched.
  Handle it explicitly.

**Traps for the header.** The dropped-release watchdog above. `@KEY0 + 26 < 256`. `gks` arity for the
ten-argument call. Repaint gating. Every division floored. Colour channels inside 0..255.

### SWITCH

**The card.** Nine apps in nine blocks, each with its own mark, so you find one without reading
anything.

**Route: `lua`.** Nine distinct 3x3 glyphs are eighty-one painted cells. As zones plus `showGrid`
this card would be `ninepads` with a different send, and overlap is a rejection reason in this
repository - the glyphs are what make it a different card. Say both halves in the route note.

**Mechanism.**

- Nine 3x3 blocks. Each carries a **nine-bit glyph**: a nine-entry table of integers, one per block,
  and cell `k` of block `z` is lit when `(g[z] >> k) & 1` is 1. Nine integers is nine literals and the
  drawing is one nested loop - the cheapest possible per-cell picture.
- **Choose the nine glyphs deliberately.** `src/lib/ui/glyph-field.ts` is HANGAR's own visual identity
  and is the right source of taste; **read it for the vocabulary and do not import it** - a catalog
  entry is a Lua string and may import nothing. Pick nine shapes that are distinguishable at three
  cells across: a full square, a hollow square, a cross, a diagonal, a corner, a bar, a T, a chevron,
  a single centre dot. **Check that the nine integers are nine distinct values and that no two glyphs
  differ by fewer than two lit cells**, with a one-off script, and paste the nine as binary in the
  SUMMARY.
- Lit cells in `@ONC`, unlit in `@OFFC` dim so the block boundaries read. Painted in Setup, layer 2;
  the pressed block flashes on layer 1 with a decay. `restsBlack: false`.
- A tap on a block sends `gks(@DELAY, 1, 1, @MOD, 0, 2, @KEY1 + z, 1, 0, @MOD)`.
- `timer: ""`. The glyph field is static.

**Traps for the header.** The bit shift is Lua 5.3 and later and is inside the restricted subset -
confirm `>>` and `&` survive `compressScript` unchanged, because the minifier is the thing that
decides canonical form and a shift is not a construct the shipped seven entries use.
**Measure that first**, before writing the rest of the entry; if it does not survive, use a
divide-and-modulo form instead and record the substitution and its cost. `@KEY1 + 8 < 256`. `gks`
arity. Colour channels inside 0..255. Code 9 on the onset filter.

**The honest limit, for the card copy.** HANGAR cannot show the keystroke; and nine glyphs are a
mnemonic, not labels - you assign the meaning, the pad only makes the nine tellable apart.
