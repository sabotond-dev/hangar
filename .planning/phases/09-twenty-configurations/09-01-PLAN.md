```

```

Locals are collected from the same text with two patterns: `local <ident>` (including
`local a,b,c` lists) and `function(<params>)` parameter names. Both are needed - a shipped entry
writes `self.touch_cb=function(s,i,e,x,y)` and then calls `s:gms(...)`, so `s` must be known.

`type`, `tostring`, `tonumber`, `ipairs`, `pairs`, `select`. Nothing else. `print` is **not** on it -
firmware's `print` costs the 256-byte protocol buffer and is not registered in the host at all.
