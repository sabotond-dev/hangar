<objective>
A fake ZONA that answers in the browser, and the probe that shows what the install store did with it.

Wave 8. Phase 6's shim (`e2e/fake-serial.ts`) can grant, pick, refuse, unplug and replug a port, and
it can be fed bytes from a committed capture - but it cannot *answer*: an install needs an
acknowledgement that echoes the request id firmware reads off the wire, and a serial report, and a
re-fetch that returns what was stored. Reimplementing a ZONA in an init script would be a second fake
that drifts from the first. So the page-side shim gains one hook - on every write it calls a Node
function when one is exposed and feeds back whatever frames it returns - and the Node side is the real
`zonaResponder` from `src/lib/transport/fixtures/synthetic.ts`, with scripted faults on top.

**That import was measured, not assumed.** On 2026-09-05 a scratch Playwright test importing
`synthetic.ts` by path listed and passed under Playwright's loader: `$lib/protocol` inside it
resolved through the tsconfig `paths` the generated `.svelte-kit/tsconfig.json` declares, and the
pinned protocol package loaded in Node exactly as it does under Vitest (its own `HEARTBEAT_INTERVAL`
log line appeared). The link is proven at the resolution level; this plan is where it becomes a
fixture.

**The probe renders no production chrome.** The panel, the confirmation and the header lock are
waves 9 to 11; this page is a plain readout of the store's fields plus a **trace** - every phase the
store passed through, in order - so a browser test can assert transient states (`snapshotting`,
`writing`) that a 40 ms round trip never leaves on screen. It is the sixth unlinked probe and obeys
the rules the other five do: prerendered, trailing slash, named nowhere in `src/routes/` outside its
own directory, describing its siblings rather than spelling them.

Purpose: SAFE-01 as a class count on a real page, SAFE-03 and SAFE-07 and SAFE-09 as states a
browser visited.
Output: one shim hook, one Node responder, one probe, one layout line, six browser tests.

**The shim hook**, in `e2e/fake-serial.ts` (Phase 6's file, one addition and two controls):

```ts
// Inside the fake port's write(): after counting the chunk,
const respond = (window as unknown as { __hangarZona?: (hex: string) => Promise<string[]> }).__hangarZona;
if (respond) {
  const replies = await respond(toHex(chunk));      // Node answers, through page.exposeFunction
  for (const hex of replies) this.#push(fromHex(hex)); // each reply is one frame WITH its terminator
}
```

| New control | Effect |
|---|---|
| `unplugAfterWrites(i, n)` | port `i` fires `disconnect` and closes its streams the moment its `n`th write arrives - the `lost` state, with the write that caused it recorded |
| `beat(i, hex)` | push one heartbeat frame into port `i` - the responder's replies never include heartbeats, so the test paces them |
| `writesOf()` | the hex of every chunk ever written, so the Node side can count by class |

**The Node responder**, `e2e/fake-zona.ts`:

```ts
import { decodeFrame, TERMINATOR } from "../src/lib/protocol";
import { heartbeatFrame, zonaResponder, rigResponder, type ZonaState } from "../src/lib/transport/fixtures/synthetic";

export interface DropAck { class_name: "CONFIG" | "PAGESTORE"; nth: number }

export interface ZonaScript {
  /**
   * Drop the nth acknowledgement of this class - one entry, or several: a
   * retried write has one ACK per attempt, so "never lands" is nth 1, 2 and 3.
   * Counts are cumulative over the page's life and survive script().
   */
  dropAck?: DropAck | DropAck[];
  /** Hold every acknowledgement of this class by this many ms (Node-side setTimeout) - the page's write() stalls with it. */
  delayAckMs?: { class_name: "CONFIG" | "PAGESTORE"; byMs: number };
  /** Answer the first CONFIG/EXECUTE with a NACK. */
  nackFirstWrite?: boolean;
  /** Answer every re-fetch with a Setup that differs from RAM. */
  mismatchRefetch?: boolean;
  /** Other modules on the cable, answering the broadcast store. */
  rig?: ZonaState[];
}

export interface ExposedZona {
  /** Outbound frames seen, decoded, by class - the SAFE-01 count. */
  seen(class_name: string, class_instr: string): number;
  state: ZonaState;
  /** One heartbeat frame (hex, terminated) for beat(). */
  heartbeatHex(): string;
  /**
   * Replace the script mid-test. page.exposeFunction cannot be re-registered,
   * and the exposed function reads a Node-side closure on EVERY call rather
   * than capturing the script at install - so this is the only way a fault
   * changes after goto. Tests 4 and 6 here and 07-12's 7, 9 and 10 use it.
   */
  script(next: ZonaScript): void;
}

/** page.exposeFunction("__hangarZona", ...) over the real responder. Call BEFORE goto. */
export async function installZona(page: Page, state: ZonaState, script?: ZonaScript): Promise<ExposedZona>;
```

The exposed function strips the terminator, decodes with `decodeFrame`, counts by class, applies
the **current** script (read from the closure on every call), calls the responder, and returns each
reply as hex **with** the terminator appended.
Frames the responder answers with nothing (a heartbeat) return `[]`.
