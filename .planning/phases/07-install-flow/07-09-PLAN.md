<objective>
The guards observe the install path bite, then the three leaves.

Wave 9. Plan 07-08 widened `PERMITTED_SPECIFIERS` so the layout could start the install store; the
mutations that prove the widening is a gate and not a comment need a component under `src/lib/ui/`
to be planted in, and this wave is the first that has one. Three mutations, each observed red, before
any composite exists to violate a rule nothing was watching.

Then three components chosen because none of them knows what a session is:

- **`PutBack`** is the way back. Secondary tier, auto width, its one Body line beneath it in a
  **72px** cell sized by exactly Phase 5's honesty-slot mechanism - every candidate string rendered,
  the inactive ones `visibility: hidden` and `aria-hidden`. The reservation is a safety reservation:
  the destructive control sits directly beneath this cell, and a line that changes count would move
  it under a reaching hand (Z-18).
- **`KeepConfirm`** is the only confirmation on the site. Inline, in place of the control that opened
  it, so there is never a second `KEEP ON DEVICE` on screen (WCAG 2.5.3). `role="group"`,
  `tabindex="-1"`, labelled by `PERMANENT`, described by its sentences; **not** a dialog, **not**
  modal, no trap. Its affirmative is bordered, never accent-filled - an accent-filled affirmative
  would be a second primary at the exact moment the site is asking for the irreversible thing.
- **`InstallState`** renders region 3's twelve blocks from the store's fields: five success-shaped
  (caption plus body) and seven failure-shaped, the latter through Phase 6's `FailureBlock` so the
  panel and the header cannot word a failure differently.

Purpose: SAFE-02's hierarchy as three tiers of one control family, SAFE-05's confirmation as a leaf a
node scan can check, DEGR-02's disabled-with-reason on every control.
Output: three mutations observed, three components, two structural tests.
</objective>

```
    <button data-testid="keep-confirm-no"  onclick={onclose}>NOT NOW</button>                                Quiet tier
  </div>
</div>
```

Block: `border: 1px solid var(--color-line)`, `border-radius: 10px`, `padding: 16px`, `background:

(a pending decision, unlike a disclosure); `Escape` inside it calls `onclose`. The 160ms opacity
fade in and out is CSS only, instant under reduced motion.
