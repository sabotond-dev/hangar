<objective>
The record, and the words - each in a module that imports nothing.

Wave 3. Two pure modules, both testable in node with no browser, both consumed by the install store
(plan 07-06) and the panel (plan 07-10), neither reaching a port or the compiler.

**The snapshot record** is the first persistent state this project has ever had. It is keyed
twice - by the module's 32-character serial key (plan 07-01) and then by page - because a page change
between the snapshot and a write would otherwise write page 3's original onto page 1, and firmware's
`currentpage` NACK is a backstop rather than a design (Pitfall 4). **An existing page entry is never
overwritten**: once `TRY ON DEVICE` has written, a re-connect's fetch returns HANGAR's own
configuration, and overwriting would destroy the only copy of what the visitor came in with. It
follows `src/lib/browse/return.ts` exactly: the store is an argument, `undefined` during prerender,
and nothing throws - a browser configured to refuse storage can throw on **property access** of
`window.localStorage`, so even that read happens behind a try in the caller (Pitfall 9). The durable
half is a courtesy; the in-memory snapshot in the store is the safety rail.

**The copy module** is `session-copy.ts`'s twin: every sentence of the approved Copywriting Contract,
once, as named consts and pure functions with zero import specifiers, so a first-paint component may
name it. The three character caps the panel's reservations rest on - honesty slot 129, `PUT BACK`
cell 129, `KEEP ON DEVICE` cell 86 - are asserted per string by name, so a reservation cannot
silently grow (Z-18).

Purpose: SAFE-04's durability as a pure record, SAFE-05's confirmation sentence and SAFE-08's honest
speed as literals a test holds character for character.
Output: two modules, two specs, thirteen tests.
</objective>

**`src/lib/device/snapshot.ts`** - pure, import-free, never throws:

```ts
export const SNAPSHOT_KEY = "hangar.snapshot.v1";

export type EventPair = { readonly setup: string; readonly timer: string };

/** Anything with the three methods; undefined during prerender. Never throws. */
export type SnapshotStore = Pick<Storage, "getItem" | "setItem" | "removeItem">;

/** The one record under SNAPSHOT_KEY. Versioned in its key AND its body, so a `.v2` cannot be misread. */
type SnapshotRecord = {
  v: 1;
  /** The module this browser last identified, so PUT BACK can be offered (disabled) with no session. */
  last?: string;
  modules: Record<string, { pages: Record<string, EventPair & { takenAt: string }> }>;
};

/** The original strings for this module on this page, or undefined. Malformed and wrong-version read as absent. */
export function readSnapshot(store: SnapshotStore | undefined, moduleId: string, page: number): EventPair | undefined;

/**
 * Persist ONLY when no entry exists for this module and page. Returns what happened:
 *   "written"     - the entry was absent and is now stored
 *   "kept"        - an entry already existed and was NOT touched (the original wins)
 *   "unavailable" - no store, a throwing store, or a full quota; the caller's in-memory copy stands
 */
export function persistIfAbsent(store: SnapshotStore | undefined, moduleId: string, page: number, pair: EventPair, takenAt: string): "written" | "kept" | "unavailable";

/** Remember which module this browser last identified. Same three outcomes; nothing throws. */
export function rememberLast(store: SnapshotStore | undefined, moduleId: string): void;
export function lastModuleId(store: SnapshotStore | undefined): string | undefined;
/** True when at least one page entry exists for the module. */
export function hasSnapshotFor(store: SnapshotStore | undefined, moduleId: string): boolean;
```

Every function reads the whole record, parses it inside a try, treats anything that is not
`{ v: 1, modules: object }` as absent, and writes the whole record back through one `setItem` inside
a try. Nothing is deleted by any function - there is no `clear`, no `forget`, no `remove` (Z-13), and
`removeItem` is in the type only because `return.ts`'s shape carries it; say in the header that
nothing calls it.
