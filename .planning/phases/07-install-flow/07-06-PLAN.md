<objective>
The install store: the snapshot, the two RAM clicks, and the way back.

Wave 6. A second runes store, beside the session and never inside it. It is a separate file for a
reason that is a test rather than taste: Phase 6 plan 06-04's test 15 scans `session.svelte.ts` for
eight write-shaped needles, and putting a write in the session would turn that gate red with no honest
replacement. So every write of this site lives here, and it borrows from the session exactly what
plan 07-04 lent: the transport view, `onClass`, `onConnection`, `announce` and `writeLock`.

The order at connect is a gate on the next step each time (07-RESEARCH Code Examples 1): the module
names itself (`fetch-serial` - a timeout here degrades to a session-only snapshot, never a throw);
both strings come back on the module's **reported** page and pass `canWriteBack` (D-03 - the empty
string is exactly the shape a fetch of a non-active page produces, and a factory-blank element is
not something Phase 2 ever saw); the pair is held **in memory first**; then, and only then, the
durable record is consulted and written **if absent**. An existing record wins over a fresh fetch,
because after `TRY ON DEVICE` a re-connect fetches HANGAR's own configuration and the record is the
only copy of the visitor's. Only after all of that does `ready` publish.

Every action shares one shape: guard the phase, capture the generation, set `writeLock`, run the
sequence through **one** `RequestQueue` per connection, classify by error **type**, and restore page
change in a `finally` on every path - a successful `CONFIG/EXECUTE` clears `page_change_enabled` and
only a `TYPE 255` heartbeat sets it back (`grid_decode.c:1279`, `:717`; the firmware's own timeout
restore is commented out).

Plan 07-07 adds flash, the failure taxonomy and the bounds to this same file. This plan builds what
they stand on and proves the promises that do not need a failure to test.

Purpose: SAFE-03's snapshot-before-write, SAFE-04's record that survives, SAFE-01 as a number, SAFE-07's
ACK-only settled.
Output: one store, one spec at eight.

**The snapshot, in the order that gates each step:**

```ts
async #snapshot(id: Identity, q: RequestQueue): Promise<void> {
  this.phase = "snapshotting";
  const T = await heavy();                            // already resolved by the session's open path
  let moduleId: string | undefined;
  try { moduleId = await T.fetchModuleKey(q, id); }   // "fetch-serial"
  catch { moduleId = undefined; }                     // unproven on hardware; degrade, never throw
  const pair = await T.fetchBoth(q, id);              // "fetch-setup", "fetch-timer" on the REPORTED page
  const guard = P.canWriteBack([pair.setup, pair.timer]);
  if (!guard.ok) { this.phase = "snapshot-failed"; return; }
  const fetched = { setup: pair.setup.actionString!, timer: pair.timer.actionString! };
  // IN MEMORY FIRST. Storage is a courtesy and must never be the reason a visitor has no way back.
  const record = moduleId ? readSnapshot(this.#storage, moduleId, id.activePage) : undefined;
  this.snapshot = record ?? fetched;                  // an existing original WINS
  this.snapshotPage = id.activePage;
  this.moduleId = moduleId;
  if (moduleId) {
    const wrote = persistIfAbsent(this.#storage, moduleId, id.activePage, fetched, new Date().toISOString());
    rememberLast(this.#storage, moduleId);
    this.snapshotDurable = wrote !== "unavailable";
  } else {
    this.snapshotDurable = false;
  }
  this.phase = "ready";
  this.#session.announce(LIVE_SNAPSHOT_SAVED);
}
```

**Every RAM action, the shape:**

```ts
async #ramLeg(action: InstallAction, strings: ConfigStrings): Promise<boolean> {
  const gen = this.#generation;
  const q = this.#queue!;
  const T = await heavy();
  this.action = action; this.leg = "ram"; this.phase = "writing";
  this.#session.writeLock = true;
  this.#armSlow();                                    // 07-07
  try {
    await T.writeBoth(q, T.targetOf(this.#identity()), strings);   // Timer, then Setup, ACK each
    if (gen !== this.#generation) return false;       // the link was replaced under us (Pitfall 11)
    return true;
  } catch (err) {
    if (gen !== this.#generation) return false;
    this.#classify(err, T);                           // 07-07 widens this
    return false;
  } finally {
    // MANDATORY on every path. See sequence.ts restorePageChange.
    await T.restorePageChange(q).catch(() => undefined);
    this.#disarmSlow();
    this.#session.writeLock = false;
  }
}
```

`tryOnDevice(config, name)` refuses (returns without touching the queue) when `config` is
`undefined`, when either string is longer than `CONFIG_MAX - 1` (908 - read from the awaited
protocol module, never restated), when the phase is not one of `ready | settled | restored | kept |
partial | nothing-landed | unconfirmed | kept-mismatch | restored-unconfirmed`, or when the session
is not `connected`. From `snapshot-failed` it runs `#snapshot` first and writes only if that lands
`ready`. On success: `lastWritten = config`, `name`, `armed` recomputed, `phase = "settled"`,
`announce(liveSettled(name))`. `putBack()` writes `this.snapshot` and lands `restored` (its store leg
is 07-07); `lastWritten = undefined`, `armed = false`.

**The connection lifecycle**, from the session's seams and nothing else:

- `onConnection("connected")`: bump `#generation`; build **one** `RequestQueue` over
  `session.transport` with `preSendDelayMs` from `#preSendDelayMs` (initially `PRE_SEND_DELAY_MS`) and
  an `onStep` that keeps the last action's steps; subscribe `session.onClass((cls) =>
  queue.deliver(cls))`; run `#snapshot`.
- `onConnection("closed")`: bump `#generation`; `queue.abort("closed")`; unsubscribe the class sink;
  drop the queue; `confirmOpen = false`; if a leg was in flight the action's catch classifies the
  `AbortedError` as `lost` (07-07); otherwise `phase = "idle"` while `snapshot`, `moduleId` and
  `rememberedModule` **stay** - the way back survives the unplug.

**`armed`** is recomputed in `observeConfig` and after every leg: `phase` is `settled` or
`unconfirmed` **and** `config` is defined **and** `config.setup === lastWritten.setup && config.timer
=== lastWritten.timer`. A knob move that lands on identical strings keeps it armed - what plays on
the module is what the strings say.
