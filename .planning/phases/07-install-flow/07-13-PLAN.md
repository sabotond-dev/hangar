<objective>
The seven things no machine can check, and the gate that says everything else is checked.

Wave 13, and the phase's last plan. Three pieces and one pause.

**The runbook.** `docs/SKELETON-RUNBOOK.md` said it and it is still true: Web Serial cannot be
automated - no CDP domain, no fake-device hook. A shim proves HANGAR's reaction to a modelled
browser, never the browser; a fake ZONA answers because it was told to. Everything a machine can
check is checked by this point. Seven rows remain (07-RESEARCH's table, with D-14's five and D-19's
three timings inside them), and each has a reason it cannot be simulated rather than a reason
nobody got to it. Three of them are **measurements**: whether a real ZONA answers
`SERIALNUMBER/FETCH` at all, how many re-fetch rounds the post-store reload took, and whether 0 ms
pacing survived two back-to-back full-size writes.

**The gate.** The full suite against the production static build through the real Worker, with the
counts asserted as Phase 7's baseline plus the phase's stated delta: **+4 files / +52 tests** on
quick, **unchanged** on sweep, **+12** on e2e. No deploy: the embargo is the user's.

**The honesty.** All five of Phase 7's success criteria carry a *(hardware)* half. They close as
**verified-by-user-pending**, in those words. The failure paths close as verified against recorded
frames and scripted faults, which is what criterion 5 asks for. A phase that marked the hardware
half done because a fake ZONA agreed with a source reading would be doing exactly the thing the
fake's own header warns about.

**The pause.** A `checkpoint:human-verify`. The first write to a real ZONA in this project is the
user's click at row B, and nothing in this plan or any plan before it performs one.

Purpose: SAFE-01 to SAFE-09 and DEGR-02 closed with qualifiers, and the hardware half handed to the
person who owns a ZONA.
Output: one runbook, two updated documents, one deferred-items file, one green suite, one unanswered
checkpoint.

    The install flow. `TRY ON DEVICE` writes the configuration on screen into the ZONA's memory in
    about a second and says `PLAYING NOW` only when both acknowledgements have arrived; `PUT BACK`

    explained.
