<objective>
The five things the cable does, in a browser, with no cable.

Wave 7. Plan 06-06 proved what a browser refuses; this proves what it does when a module is really
there. Four of these five are CONN-06's hardware half, and the fifth is SAFE-01's — and every one of
them is a state a manual tester reaches by unplugging a cable at exactly the right moment, which is to
say: never reliably, and never twice.

Two details decide whether these tests are evidence or theatre:

- **Identification runs on real captured bytes.** The rx chunks come out of
  `zona-hardware-a-hb-on-pace-0.json` — 119 chunks recorded from a real ZONA RevH on firmware 1.5.5,
  active page 3 — read in Node and fed into the fake port. A hand-written heartbeat would test the
  test.
- **The replug test asserts against the NEW object.** `__hangarSerial.replug()` mints a fresh port,
  exactly as Chromium does, and the assertion that matters is that the following click opens it with
  **zero** `requestPort` calls. A session holding the pre-unplug object would either ask for the
  picker again or fail with a `NetworkError`, and both are visible here.

Purpose: CONN-06 end to end, CONN-04's recovery copy on screen, and SAFE-01 asserted as a count rather
than a claim.
Output: five more browser tests, the suite at `PREV_E2E + 5`.
</objective>

<interfaces>
**Feeding the capture.** Read in Node, at module scope of the test file, filtering exactly as
`FakeTransport.fromCapture` does — rx chunks only:

```ts
const capture = JSON.parse(
  readFileSync("src/lib/transport/fixtures/zona-hardware-a-hb-on-pace-0.json", "utf8"),
);
const RX: number[][] = capture.events
  .filter((e: { dir: string; kind: string }) => e.dir === "rx" && e.kind === "chunk")
  .map((e: { hex: string }) => [...Buffer.from(e.hex, "hex")]);
```

A helper `identifyWith(page, index)` feeds enough of `RX` for `identify()` to resolve — the ZONA's own
heartbeat carrying a page report, which the hardware run measured at roughly 250 ms of traffic — and
waits for `session-phase` to read `connected`. Feed chunks in order and stop at the first frame that
completes identification rather than replaying all 119; record how many chunks that took, because it
is a fact about the capture that the next reader will want.

**Two additions to `e2e/fake-serial.ts`**, both small:

| Call | Effect |
|---|---|
| `requests()` | how many times `requestPort()` has been called — the assertion that makes "one click, no picker" falsifiable |
| `openCount(i)` | how many times `open()` was called on port `i` — so "never auto-open" is a number |

and **`writes()` is 0**. This is SAFE-01 as a number over a whole visitor journey, and it is the
browser-side twin of the node test in 06-04.
