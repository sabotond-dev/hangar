<objective>
The same nine states, this time on the site a visitor actually opens.

Wave 13. Plans 06-06 and 06-07 proved the session against a plain-text probe, which is what let the
machine be tested before any component existed to hide a bug in. These five prove the **shipped
chrome**: the header slot, the disclosure, the note, the panel and the live region, on the routes a
visitor reaches.

Two of them are worth more than the others.

**Navigation.** D-05's whole claim is that one connection survives a move from `/` to `/c/{id}/` to
`/browse/`, and it is a claim about SvelteKit's client router keeping the module graph alive rather
than about any code this phase wrote. It is also the claim a full reload quietly breaks, which is why
`getPorts()` exists. A test that clicks its way across three routes with an open port and asserts the
identity is still on screen is the only thing that would notice a stray `rel="external"`, a
`window.location` assignment or a component that re-mounts the session.

**The WebKit header.** DEGR-01's promise is that the browse-only half of the site carries it, and
DEGR-02's is that a control that cannot work is present, disabled and says why — never hidden. On the
engine that can never install, the header must say which browsers can, name no engine, and cost the
visitor no reserved region they will never use.

Purpose: CONN-06 across navigation, CONN-07's verified identity on screen, SAFE-01 as a write count
over a real journey.
Output: five more browser tests, one tagged, the suite at `PREV_E2E + 6`.
</objective>

<interfaces>
**The five titles**, in order:

10. `the header shows the module a visitor connected to`
11. `one connection survives the front door, a configuration and the catalog`
12. `a failure from the header opens its recovery and hands focus back on Escape`
13. `@webkit the header names the browsers that can install and offers nothing to press @webkit`
14. `a session transition is announced once, and the other two regions stay quiet`

**Selectors this plan uses**, all shipped: `device-slot`, `device-slot-label`, `device-slot-caption`,
`device-details`, `device-mark`, `device-note`, `failure-block`, `session-live`, `browse-link`,
`try-on-device`, `connect-status`, `tuning-live`, `browse-live`.

**Test 11's route walk** is a **client-router** walk, never three `goto`s: `/` -> click `BROWSE ALL`
-> click a card -> back to `/` through the wordmark link. A `goto` would be a fresh document and would
prove the opposite of what the test is named for. Assert on each route: the slot's label is the
identity summary, `requests()` is still 0, and `writes()` is 0.

**Test 13's setup** deletes `Navigator.prototype.serial` in an init script and installs **no** shim.
It asserts, **in this order and no other**:

1. the slot renders and is not hidden;
2. **its caption has settled at `Not in this browser`** — this is the assertion that proves the
   capability decision has already happened, and everything below depends on it;
3. the disclosure holds the copy naming Chrome, Edge and Firefox 151, and the page text contains no
   `Chromium`;
4. **the note region is absent entirely** (`device-note` count is 0);
5. the panel's `connect-status` still carries the same reason — the two-surface DEGR-02 promise.

**The order is the test.** A `device-note` count of 0 taken before the caption settles is 0 because
nothing has rendered yet, not because the note is absent by design, and it would pass just as happily
on a page that was about to paint a 152px region and then take it away. Waiting on the settled caption
first is what turns step 4 into evidence.

**Test 14** connects, waits for the trailing window, and asserts `session-live` reads the connected
sentence exactly once while `tuning-live` and `browse-live` are unchanged. Then it turns a knob and
asserts the reverse: the tuning region speaks and the session region does not. That pair is what makes
D-17's disjoint-trigger-sets claim a test rather than a paragraph.

that skipped it would let a bug that leaked a connection across reloads look like a feature.

stale phase could satisfy — Phase 5 recorded that lesson against the meters.
