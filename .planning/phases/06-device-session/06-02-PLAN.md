<objective>
One module, no imports, every word the session says.

Wave 2. `06-UI-SPEC.md`'s Copywriting Contract is a table of about thirty strings, and they are read
by five components across two surfaces. Phase 5 already proved the shape this wants:
`src/lib/tune/copy.ts` carries **zero** imports — not "no vendor imports", zero — because Phase 4's
chunk guard matches specifier text, and a copy module that imports nothing can be named by anything,
including a header component that renders on the first paint of `/`.

This module is that, plus two things that are not strings and belong here for the same reason:

- **`slotStateOf(phase)`** — the nine-slot-state table as a pure function, so `DeviceSlot.svelte`
  becomes a dumb renderer and the table is tested in node rather than in a browser.
- **`capabilityOf`**, moved here from `try-on.ts` and re-exported from it. The reason is a layout
  one: the header note is a **152px reserved region that is absent entirely in `unsupported` and
  `insecure`** (06-UI-SPEC, Y-23). If capability could only be known after `try-on.ts` had been
  fetched, every visitor would paint the note and a WebKit visitor would lose it a tick later,
  shifting the headline and the coverflow on the one browser that can least afford a surprise. With
  the rule in an import-free module the session decides capability **synchronously**, in the first
  hydrated frame, and nothing ever moves. One definition, one test, one new home.

Purpose: CONN-02's two distinct messages, CONN-03's pre-click line, CONN-05's empty-picker branch and
CONN-08's identity line, all in one place before any component exists to render them.
Output: one new module, one new spec, one re-export.
</objective>

<interfaces>
**The taxonomy, as one union.** Seventeen phases; the **nine named states** of 06-UI-SPEC are the
subset marked below. `already-open` is deliberately **not** a phase: it is an `OpenFailure` key that
plan 06-03 maps onto the `unknown` phase, exactly as the UI spec folds it into the `unknown` row.

```ts
export type SessionPhase =
  | "starting"                  // before the capability is read; the prerendered markup
  | "unsupported"               // named state 1  -> S0a
  | "insecure"                  // named state 2  -> S0b
  | "idle"                      // -> S1
  | "detected"                  // -> S2
  | "choosing" | "opening" | "identifying"   // -> S3
  | "connected"                 // -> S4
  | "unplugged-while-connected" // named state 3  -> S5
  | "cancelled"                 // named state 4  -> S6
  | "port-busy"                 // named state 5  -> S6
  | "not-zona"                  // named state 6  -> S6
  | "silent"                    // named state 7  -> S6
  | "unplugged-at-open"         // named state 8  -> S6
  | "unknown"                   // named state 9  -> S6
  | "forgotten";                // -> S7

export type SlotState = "S0a" | "S0b" | "S1" | "S2" | "S3" | "S4" | "S5" | "S6" | "S7";
export function slotStateOf(phase: SessionPhase): SlotState;

/** The six of the nine that render failureCopy verbatim, and the three HANGAR authors. */
export const FAILURE_COPY_STATES = ["unsupported","insecure","cancelled","port-busy","unplugged-at-open","unknown"] as const;
export const AUTHORED_STATES = ["not-zona","silent","unplugged-while-connected"] as const;
export const NAMED_STATES = [...FAILURE_COPY_STATES, ...AUTHORED_STATES] as const;  // nine
```

**The three authored blocks**, each taking the rendering surface's control label:

```ts
export interface SessionBlock { title?: string; detail: string; steps: string[] }
export function notZonaBlock(moduleType: string | undefined, label: string): SessionBlock;
export function silentBlock(seconds: number, label: string): SessionBlock;
export function unpluggedWhileConnectedBlock(): SessionBlock;   // one sentence, no title, no steps
```

`notZonaBlock` keeps Phase 4's title and body verbatim and takes 06-UI-SPEC's **amended** steps —
`Plug in a ZONA` then `Click {label} again` — because Phase 4's `Disconnect` named a control that is
not on the screen after the session closed the port. `silentBlock` keeps Phase 4's title and body and
amends step 2 to `Click {label} again and pick a different port`.

**The identity, in pieces**, because the firmware and the page number are monospaced numeric runs
inside an otherwise-Quicksand line (06-UI-SPEC, Y-18). The module returns the parts; the component
does the markup:

```ts
export function firmwareText(fw: { major: number; minor: number; patch: number }): string; // "1.5.5"
export function moduleTail(others: string[]): string | undefined;      // "with EN16, BU16"
export function identitySentence(fw, page: number): string;            // "Firmware 1.5.5, active page 3."
export function identityDescription(fw, page: number): string;         // "... Opens device details."
export function multiModuleLine(others: string[]): string | undefined; // "Also on the cable: EN16, BU16."
```

`others` arrives already sorted by the session (by `sx`, then `sy`) and already carrying
`unknown module` for a missing `moduleType`; this module sorts nothing and looks nothing up.

**The five live-region sentences** (06-UI-SPEC, Copywriting Contract):
`LIVE_DETECTED`, `liveConnected(fw, page)`, `LIVE_DISCONNECTED`, `LIVE_UNPLUGGED`, `LIVE_FORGOTTEN`.
A failure announces its own `title` and nothing else, so there is no sixth string.
