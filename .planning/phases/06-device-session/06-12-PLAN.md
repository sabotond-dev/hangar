<objective>
The panel stops owning a port it was only ever borrowing.

Wave 12. `TRY ON DEVICE` is unchanged in fill, size, position, label and hover (D-01). What changes is
where its truth comes from, and the list is exact:

| Concern | Before | After |
|---|---|---|
| State | the component holds `phase`, `failure`, `identity`, `moduleType` | it reads them from the session and holds none |
| The port | the component opens it and owns its lifetime | the session owns it |
| `release()` on un-choose | closes the port | **closes nothing.** The port belongs to the session and survives un-choose, stepping and navigation |
| `onDestroy` | closes the port | does not close the port |
| Tab hidden | `closeOnHide()` closes the port on `pagehide` | the session owns that, and switching tabs does not change the header |
| `aria-live` on the status region | `aria-live="polite"` | **removed — the only `aria-live` this phase removes anywhere** |
| The honesty slot | three strings, 72px reservation, sizing twins | **unchanged. No fourth string.** |
| The idle connect-state region | empty | the pre-click explanation, except in the two capability states |

**Phase 4's W-20 already said the port belongs to the session.** This is the phase where that stops
being aspirational.

**One hazard has its own name in the research** (Pitfall 7): `e2e/first-experience.e2e.ts` asserts the
unsupported copy **inside `getByTestId("connect-status")`**, in the panel. It asserts a location as
well as a message, so it can fail — or, worse, pass for the wrong reason if the panel starts rendering
nothing. The decision here is deliberate and it is to **keep the capability block in the panel**:
DEGR-02 says the reason is rendered adjacent to the disabled control, and there are now two disabled
controls. The shipped test therefore stays green with no edit, and this plan proves that rather than
hoping.

Purpose: D-01's consumer-not-owner, CONN-03's explanation in its second mount, CONN-02's degrade copy
kept where a shipped gate can see it.
Output: one component rewritten inward, one gate grown by one test.
</objective>

**What the component reads**, all of it from the session:

```ts
const state   = $derived(slotStateOf(session.phase));
const connecting = $derived(session.phase === "choosing" || session.phase === "opening" || session.phase === "identifying");
const block   = $derived(session.failureFor(TRY_ON_LABEL));   // the panel's own label (Y-13)
const disabled = $derived(
  session.phase === "starting" || connecting ||
  session.phase === "connected" ||
  session.phase === "unsupported" || session.phase === "insecure" ||
  budgetReason !== undefined,
);
```
