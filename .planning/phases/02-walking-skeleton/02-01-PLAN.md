`encode_packet` contract (`dist/index.js:3925-3998`):
- returns `undefined` if the descriptor is `undefined`; guard it.
- returns `{ serial: number[], id: number }`. **`id` is the correlator** — a module-level counter
  cycling 1..255. Capture it before the write; it is not on the descriptor you passed in.
- forces `SX = 0, SY = 0, MSGAGE = 0`; adds 127 to `DX`/`DY`. So `DX: 0` is IS_ME (wire `7f`) and
  `DX: -127` is IS_GLOBAL (wire `00`).
- writes any `class_parameters` value with declared `length === 0` as raw `charCodeAt(i)` bytes —
  the ACTIONSTRING is not escaped. A non-ASCII character makes `.length` disagree with the bytes.

Round trip observed on this machine for a `CONFIG/EXECUTE` with `ACTIONSTRING: "--[[@cb]]print(1)"`:

```
frame.length              1                (one class block)
class_name / class_instr  "CONFIG" / "EXECUTE"
class_parameters          { ACTIONLENGTH: 17, ACTIONSTRING: "--[[@cb]]print(1)",
                            ELEMENTNUMBER: 0, EVENTTYPE: 6, LASTHEADER: 1,
                            PAGENUMBER: 0, VERSIONMAJOR: 1, VERSIONMINOR: 5, VERSIONPATCH: 5 }
brc_parameters            { DX: 0, DY: 0, ID: 1, LEN: 63, MSGAGE: 0, PORTROT: 0,
                            ROT: 0, SESSION: 193, SX: -127, SY: -127 }
```

Note `SX/SY` decode as `-127` on an OUTBOUND frame (encode forces the source to 0 on the wire and
the decoder subtracts 127). An INBOUND frame from the USB-attached module reports `SX: 0, SY: 0`.

**The offset collision.** `CONFIG.LASTHEADER` and `CONFIG.VERSIONMAJOR` share offset 5, length 2.
On an `ACKNOWLEDGE`/`NACKNOWLEDGE` those bytes are the request's BRC id (firmware sets
`CLASS_CONFIG_LASTHEADER`, `grid_decode.c:1307`). On a `REPORT` they are the firmware's protocol
major version. Use `LASTHEADER` **only** on ACK/NACK. The round trip above shows the trap: an
outbound EXECUTE decodes `LASTHEADER: 1` because `VERSIONMAJOR` is 1.

`decode_packet_classes` mutates the array in place and returns `undefined`. A single BRC frame
carries **more than one class** as the normal case (a `TYPE 1` heartbeat carries `PAGEACTIVE/REPORT`
in the same frame; a `PAGESTORE/ACKNOWLEDGE` carries a `DEBUGTEXT`). Iterate; never take `[0]`.

Fields beyond a frame's actual length decode as `undefined`. A `CONFIG/ACKNOWLEDGE` is a six-byte
class block, so its `PAGENUMBER`, `ELEMENTNUMBER`, `EVENTTYPE`, `ACTIONLENGTH` and `ACTIONSTRING`
are all `undefined`. A matcher that requires them will never match an ACK.

Typings are loose: `getProperty(key: string): any`, `decode_packet_frame(...): any`,
`encode_packet(descriptor: any)`. Declare HANGAR's own interfaces and narrow at the boundary rather
than spreading `any` — but `@typescript-eslint/no-explicit-any` is only `recommended`-level here, so
a single documented `any` at the package boundary is acceptable if narrowing needs it.

```ts
// The rx frame scanner: EOT + LF, with a cursor and a ceiling (FOUND-01).
//
// Shape from grid-editor/src/renderer/serialport/serialport.ts:143-185. Two
// deliberate differences: a cursor, so a long partial frame is not rescanned
// from zero on every chunk, and an 8 KB ceiling, so a link that never produces
// a delimiter cannot grow the buffer without bound.
//
// Known limitation, shared with the desktop and worth writing down: the
// delimiter is not escape-safe. A byte 4 three positions before a byte 10
// INSIDE a config string would split a frame early; both halves then fail their
// checksum and are dropped. Minified Lua is printable ASCII, which is why
// descriptors.ts asserts that before a write - and why the torn-frame test
// below exists.
//
// Copyright (C) 2026 Botond Sandor. Licensed under the GNU GPL v3 or later.
export const EOT = 4;
export const TERMINATOR = 10;
/** About eight maximum-size frames. Anything larger is not a frame. */
export const MAX_BUFFER = 8192;

export class FrameScanner {
  private buf: number[] = [];
  private scanned = 0;
  /** Fired when the ceiling is hit and the buffer is dropped. */
  onOverflow: (() => void) | undefined;

  get buffered(): number {
    return this.buf.length;
  }

  push(chunk: Uint8Array | number[]): number[][] {
    for (const b of chunk) this.buf.push(b);
    const out: number[][] = [];
    let start = 0;
    // i-3 needs three bytes of lookback, so the scan never starts below 3.
    for (let i = Math.max(this.scanned, 3); i < this.buf.length; i++) {
      if (this.buf[i] === TERMINATOR && this.buf[i - 3] === EOT) {
        // The frame EXCLUDES the terminator and INCLUDES the two checksum
        // characters - exactly what decode_packet_frame expects
        // (dist/index.js:4030-4034 requires array[length-3] === EOT).
        out.push(this.buf.slice(start, i));
        start = i + 1;
      }
    }
    this.buf = this.buf.slice(start);
    this.scanned = start > 0 ? 0 : this.buf.length;
    if (this.buf.length > MAX_BUFFER) {
      this.buf = [];
      this.scanned = 0;
      this.onOverflow?.();
    }
    return out;
  }
}
```
