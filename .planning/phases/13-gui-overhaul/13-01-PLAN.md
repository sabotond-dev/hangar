## The allowlist's shape, and the four ways it goes red

```
ALLOWLIST = [
  { file: "src/app.css",                       declarations: 2, clearedBy: "13-03" },
  { file: "src/lib/ui/PadFrame.svelte",        declarations: 1, clearedBy: "13-04" },
  ...
  { file: "src/lib/ui/ColourPicker.svelte",    declarations: 9, clearedBy: "13-09",
    circles: 3, circleLines: [829, 857, 872],
    note: "three 50% survive D-10/D-15 and move OFF the allowlist onto the permitted rule" },
  { file: "src/lib/ui/Knob.svelte",             declarations: 10, clearedBy: "13-09",
    circles: 3, circleLines: [598, 653, 674],
    note: "dot rail, slider thumb, home mark - three 50% survive D-15, the other seven are cleared" },
]

`circles` is **summed across the list and asserted to be exactly 6**, and the collected `circleLines`
are asserted against D-15's six `file:line` pairs as a set, so a circle that moves file or line is a
red test and a deliberate amendment rather than a silent drift.
```

1. A file not on the list carries a declaration above zero → red, naming the file and the value.
2. A file on the list carries **more** declarations than its row says → red. The count only shrinks.
3. A file on the list carries **none** → red as a **stale row**, because a cleared row that stays is
   how an allowlist becomes a permission.
4. Any `rounded`, `rounded-md`, `rounded-full` (or any `rounded*` token) inside a `class` string
   anywhere under `src/` → red, with no allowlist at all. Tailwind utilities were never used here and
   this is the door that would let them in.

**`0`, `0px` and `inherit` are not declarations for this purpose** - `inherit` from a zero is zero, and
the focus ring at `app.css:292` inherits from whatever it wraps. State that exemption in the header
with the line number, so it is a decision and not an oversight.

**The literal `50%` is permitted by layer A and CHECKED by layer C.** Layer A cannot know a box's
aspect ratio; layer C can. The two halves of D-10 are therefore in two different layers on purpose,
and the header says so.
