<objective>
The Sandbox's data half: a region model whose rules are unrepresentable to break, and an emitter whose
cost is measured rather than hoped.

**This is the first wave that cannot start before Phase 12 closes**, and the reason is not scheduling:
the emitted callback calls Phase 12's touch library by name. **A revision of the Phase 12 plans is in
flight and will change 12-07's `Q` (same-id expiry) and its callers.** The function set `Q A E X F D`
is stable in outline, `F` is dropped, and `Q`'s signature and semantics are **not final**. So the rule
for this plan and the three after it: **read `12-07-SUMMARY.md` at execution time and consume the
library's final shape from it - never from `12-07-PLAN.md`, never from `13-RESEARCH.md`.**

**The measured facts this plan is built on** (`13-RESEARCH.md` §3.1, produced in this tree with the
pinned `compressScript`):

1. **The naive compiler is dead.** A generic four-type dispatcher costs **1,067 with one element on the
   surface** and **1,166 with four** - over a whole event's budget before anything is placed. Any plan
   that assumes "emit a block per element" is planning something that cannot be installed.
2. **Dead-branch elimination is worth about 470 characters.** Emitting only the branches a surface
   actually uses takes the four-fader case from 1,166 to **697**. It is the cheapest large win and it
   needs no firmware question at all.
3. **The split is what makes the PDF's own surface possible**: a generic runtime on a second system
   slot (**861**) plus a per-surface data table on the touch Setup (**366** at four elements, **811** at
   sixteen). The runtime is 13-15's; **this plan builds the data half**, which fits in either branch.

**Overlap is not discouraged, it is unrepresentable.** §8 says default to preventing overlaps. With an
81-entry **cell-to-region map** `M`, each cell holds **one** region index - so an overlapping surface
cannot be expressed, let alone emitted. `M` costs 165 characters and replaces a search loop that costs
more than that at four elements and much more at sixteen. Layered hit-testing (§8's conditional) would
need `M` to hold a list, and that cost is the reason not to.

**The boundary matters at onset and only at onset.** Probe A Q2 measured the cell boundary as **one unit
wide** - a still finger at x=71/72 flips cells. For a *region* it matters much less, because a contact
**keeps the region it landed in** for the whole gesture; it matters at the **press**, where a finger on
the seam between two regions is a coin flip. Phase 12's hysteresis cannot help on a first sample (there
is no prior cell). **So the mitigation is in the editor, not the runtime**: warn when two regions are
edge-adjacent with no gap, which is §8's *"explain the conflict at the affected region"* applied one
step earlier.

**One-based in the interface, zero-based in the model.** The PDF's inspector shows `Column 1, Row 1` for
the top-left cell. HANGAR is zero-based everywhere (`glag(0, n)`, `n = row*9 + col`). That translation
is a real interface and it gets a **named door**, the way `knobPosition` and `colourPosition` already
are - not four inline `- 1`s in four components.

Purpose: the Sandbox's rules, expressed as data structures, and its cost, expressed as measurements.
Output: five modules, nine tests, five measured costs. Term `+2 / +9`.
</objective>

## The model

```ts
type ElementKind = "fader-v" | "fader-h" | "button" | "xy" | "knob";
type Region = {
  id: string; name: string; kind: ElementKind;
  col: number; row: number; w: number; h: number;   // ZERO-based, 0..8
  cc: number; cc2?: number; channel: number;         // 1..16 in the UI, 0..15 on the wire
  colour: [number, number, number];                  // RGB444
  latch?: boolean;                                   // button only
};
type Surface = { id: string; name: string; regions: Region[]; schema: 1 };
```

**The cap is sixteen** (D-14 Q4) with the live budget meter, because *"you have room for four more"* is
a better interface than a hard refusal - and the meter already exists.

**The named door:**

```ts
export const toDisplay = (zeroBased: number) => zeroBased + 1;
export const fromDisplay = (oneBased: number) => oneBased - 1;
```

Two functions, one header paragraph, and **every component uses them**. The header cites
`knobPosition` and `colourPosition` as the precedent.

## The emitted shapes

```
G = { {x0,x1,y0,y1,type,cc,cc2,ch,r,g,b}, ... }   the region table, one row per region
M = { ...81 numbers... }                          cell -> region index, 0 for none
```

**`x0..y1` are precomputed in raw 0..127 units**, not derived from cells at runtime: a fader's value is
`127-(y-y0)*127//(y1-y0)` and the compiler knows `y0` and `y1` exactly. This is the single largest
runtime saving after dead-branch elimination.

Measured, from the research: `M` alone is **165**, a four-row `G` is **141**, and the full touch Setup
with the callback is **366** at four elements and **811** at sixteen.

**Dead-branch elimination** is a property of the emitter: the branch text for a kind is emitted only if
some region uses it. **Prove it with a measured pair** - four vertical faders with and without the
other three branches - and record both numbers. The research's pair is 697 against 1,166; **re-measure
rather than quoting it.**

## The geometry rules, all six

1. **On the surface**: `col + w <= 9`, `row + h <= 9`, `col >= 0`, `row >= 0`, `w >= 1`, `h >= 1`.
2. **No overlap**: the cell map is built by writing each region's cells; a cell written twice is a
   conflict, reported with **both** region names.
3. **A minimum size per kind**: a Knob needs a centre dead zone, so a 1x1 or 2x2 knob is refused -
   **13-15 derives the exact rule from the arithmetic** and this plan takes it as a parameter rather
   than inventing it.
4. **Duplicate to a free area**: search for a free `w x h` window in the cell map, in reading order;
   if none exists, **offer resize and never silently delete** (§8's own words).
5. **The previous valid value survives an invalid edit** (§8), with an inline message until corrected.
6. **Edge-adjacency warning**: two regions sharing a boundary with no gap raise a warning - not an
   error - naming both, because Probe A Q2's one-unit boundary makes a press on the seam a coin flip.

## The cap and the meter

Sixteen regions maximum, **and the meter is the real gate**: a surface of sixteen tiny faders fits, a
surface of eight with long colour literals might not. `cost.ts` answers *"this surface costs N of 908,
and you have room for about M more elements"*, where M is derived by adding a representative region and
re-measuring - **not** by dividing.
