## The three rules this plan ships

### 1. The pill (§19.1b, A-41)

**One rule in `src/app.css`, named `.pill`, applied by class.** Not nine copies in six files.

| Property | Value |
|---|---|
| Radius | `border-radius: 999px` — §6 exception 7. Degenerate, resolves to half the block size, cannot drift |
| Border | `1px solid var(--color-line)` — 3.31:1, above the 3:1 non-text floor, and the Secondary tier's existing border |
| Fill | `transparent`, except where the control already owns one |
| Inline padding | `24px`, the `lg` token. At the 44px block floor the radius resolves to **22px per end**, so 24px clears the curve by 2px |
| Floor | `min-block-size: 44px` **and** `min-inline-size: 44px` |

**Which tiers take it, and which are byte-untouched:**

| Tier | Controls | Shape |
|---|---|---|
| Primary | `TRY ON DEVICE` | **pill radius on its existing accent fill.** No new accent use |
| Secondary | `PUT BACK`, both confirmations' affirmatives, `COPY LINK`, `TURN IT DOWN`, `MIX TWO` | **pill outline** |
| Word rows | `Knob.svelte`'s options, `ColourPicker.svelte`'s knob selector, `BrowseToolbar.svelte`'s `SORT`, the facet chips | **pill outline; the selected option's existing treatment is UNCHANGED** — it is reserved-list item 8 already and touching it risks a ninth accent use |
| Quiet | `KEEP ON DEVICE`, `NOT NOW`, `DISCONNECT ZONA`, `BROWSE ALL`, `HOLD`/`HELD` | **untouched.** Borderless, shapeless |
| Bare | `CLEAR` | **untouched.** No border, no radius, no background |

**Pilling Quiet would give `KEEP ON DEVICE` a border and flatten it into Secondary, which is the exact
regression §10.2 exists to prevent. Pilling Bare would give `CLEAR` a box, and A-24's whole argument
is that it has none.** Where D-15's "universal pill" and this ladder collide, **the ladder wins**.

**`ScreenToggle.svelte` is exempt and the exemption is declared.** It is the one control that names
the CRT vocabulary and it renders in the footer of every route **including the front door**, so a pill
there would put an instrument shape on a front-door surface. Assert the exemption; do not leave it as
an omission.

### 3. The headline, the metadata and the rows (§19.1c, §19.1d, §19.1f, A-42)

**Tabular rows without rules.** Column alignment carries the row: **no divider, no border, no zebra,

depends on the second one. **Reference C's dense tabular listing is NOT adopted as `/browse/`'s
