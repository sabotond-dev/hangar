<objective>
Two tuning ideas the survey could not find in any product in the category — and the small one that
enables both.

Wave 9. Blocked on 10-08, whose lattice knob the forecast now has to cost.

**T1 — knob locks.** A 44px toggle at the end of every knob row. `SURPRISE ME` and `MIX TWO` re-roll
only unlocked knobs. *"I love this colour, surprise me with everything else."* It is the highest-value
smallest change in `10-RESEARCH.md` §5.3 and it is what makes T4 tractable in 10-11.

**T2 — the budget as a live forecast.** No editor in the category shows what a change will cost
**before** you make it. Grid Editor's own counter is a readout; Novation, Elgato, Loupedeck, TouchOSC
and Bome have no budget at all. This is the idea that turns HANGAR's most peculiar constraint into its
best moment, and it is the honest answer to the picker's character-cost problem before the picker
arrives.

**Two amendments this costs, both named and both small:**

1. **A fifth `--font-mono` use.** Phase 5 confined the mono stack to four; the delta is the fifth, and
   it qualifies for exactly the reason W-03 introduced the stack: *it is a number that changes as a
   pointer moves, and it must not jitter horizontally.*
2. **A fifth permitted typographic character: `−` U+2212.** A hyphen-minus in a signed numeral, on a
   site that ships U+2019, U+2026, U+2014 and U+00B7, is precisely the inconsistency the copy contract
   exists to prevent. **Permitted in the forecast delta and nowhere else**, and asserted so.

**Two things this plan must not spend.** The accent reserved list stays at **eight**: a held knob is
signalled by the word changing `HOLD` → `HELD` and by the default marker changing from a 2px
`--color-line-soft` dot to a 2px `--color-line` bar spanning the selected option — **two non-colour
channels, no accent.** And `--color-over` stays at **exactly three uses**: an over-budget forecast
would be a fourth, so instead the option is already `disabled`, which means an unaffordable forecast
cannot be hovered. On today's shelf neither branch is reachable at all — 10-08 measured 268 characters
free on the dearest colour-bearing preset — so it is a guard on a guard.

Purpose: TUNE-04 (locks) and TUNE-02 (the forecast).
Output: one toggle per knob, one ghost fill, one signed delta, one newly reachable exhaustion path.
</objective>

**T2's contract.**

| Property | Value |
|---|---|
| Trigger | pointer hover **and** keyboard focus on any knob option. Gated behind `@media (hover: hover)` and `:focus-visible`; **never on touch**, where it would add latency to the gesture HANGAR is most careful about |
| What is forecast | **`cost()` only, never `fit()`.** `fit()` is N+1 minifier calls at roughly 4.4 ms on a fitting state; forecasting *n* options per knob would be *n* times that |
| Caching | memoised on the index vector, debounced in the same shape TUNE-02 already uses for recompiles |
| The meter | a **ghost fill**: `--color-line-soft` from the current value to the forecast value, behind the accent fill. | The number | a signed delta beside the hovered option, `--font-mono` 12px, `--color-ink`: `+6`, `−3`, `0`. **U+2212, not a hyphen** |
| Hidden expansion | `Choosing this would put Setup at {n} of 908.` (**44**), so the forecast is not pointer-only information |
| Over budget | the delta would render in `--color-over` — **and that fourth use is not taken.** The option is already `disabled`, so an unaffordable forecast cannot be hovered |
