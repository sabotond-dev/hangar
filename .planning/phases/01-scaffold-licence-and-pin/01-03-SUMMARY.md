## The notices generator's determinism check

`THIRD-PARTY.md` and `licenses/` are committed, so `git diff --quiet` over them is a real assertion rather
than a vacuous one over untracked files. Checked three ways:

| Check                                                                                                              | Result                                                          |
| ------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------- |
| md5 of `THIRD-PARTY.md` before and after `npm run format` reformatted `scripts/gen-licenses.mjs`, then regenerating | identical — reformatting the generator did not move its output   |
| `npm run licenses` twice in a row, then `git diff --quiet -- THIRD-PARTY.md licenses`                              | exit **0**                                                       |
| `npm run licenses` again during the final verification block                                                        | exit **0**, tree still clean                                     |

Determinism comes from sorting the checker's entries by their `name@version` key with a plain byte
comparison (no `localeCompare`), a fixed header, and clearing `licenses/` before re-materialising it so a
removed dependency cannot leave a stale notice behind.

```

- [@wasm-fmt/lua_fmt@0.2.0](https://github.com/wasm-fmt/lua_fmt) — MIT
```

`licenses/` holds `@intechstudio/grid-protocol@1.20260825.1135-LICENSE.txt` (the GPLv3 text) and

## Decisions Made

- **`licenses/` and `THIRD-PARTY.md` are committed, not gitignored.** Research's suggested `.gitignore`
  listed `licenses/`. Three reasons to commit instead: `npm run build` must be reproducible from a clean
  clone without first running the checker; the source archive should carry the notices it references (and
  it now does — both files appear in the archive listing); and the staleness spec can then read them
  directly instead of shelling out, which keeps it in the sub-second inner loop. `licenses/` therefore does
  not appear in `.gitignore`.
- **The notices line states the inference explicitly.** license-checker reports `GPL-3.0*`, where the
  asterisk means "read out of the LICENSE file". A bare trailing asterisk in markdown is easy to miss and
  easy to mistake for a formatting artefact, so the generator emits the normalised token followed by
  `(inferred from the shipped LICENSE file)`. The allowlist comparison strips the asterisk; the display
  keeps the fact.
- **Stale archives are deleted before the new one is written.** Not in the plan, but `build/` accumulating
  `source-<old-sha>.tar.gz` alongside `source-<new-sha>.tar.gz` would let a visitor download source that
  does not correspond to the bundle they just ran — the precise failure §6(d) exists to prevent.
- **The `execFileSync(..., { shell: true })` invocation was kept as specified**, including its Node 24
  `DEP0190` deprecation notice on stderr. The same pattern is already in `src/lib/format-parity.spec.ts`
  from plan 02, so the repo stays internally consistent; the notice is informational and neither run fails.

## Issues Encountered

- **`npm uninstall` does not restore `package-lock.json` byte-exactly on this machine.** The committed
  lockfile is tab-indented; npm rewrites it with two spaces. Worth knowing for plan 05's deploy gate, which
  refuses to run on a dirty tree: any `npm i` / `npm uninstall` round trip leaves the lockfile reformatted
  even when the dependency set is identical, and needs an explicit `git checkout -- package-lock.json`.
  Both negative checks here handled it that way and both files were verified by md5 afterwards.
- **`DEP0190` deprecation notice.** Node 24 warns whenever `execFileSync` is given an args array together
  with `shell: true`. Both `scripts/gen-licenses.mjs` (as the plan specifies) and plan 02's
  `src/lib/format-parity.spec.ts` trigger it, so it appears in `npm run build` output and in
  `npx vitest run`. Cosmetic; no run fails. Left alone rather than deviating from the specified invocation.
- **The `licenses/` layout is nested, not flat.** `license-checker-rseidelsohn --files` preserves the npm
  scope as a directory, so the tree is `licenses/@intechstudio/...-LICENSE.txt`, and `ls licenses | wc -l`
  counts two scope directories rather than two files. Both the acceptance criterion (at least 2) and the
  recursive GPL-text grep pass, and `cpSync(..., { recursive: true })` carries the whole tree into `build/`.
