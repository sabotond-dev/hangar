<objective>
Turn "import paths only" from a promise into an assertion.

Wave 2. `depends_on` is semantic; executors run one plan per wave in the main tree.

VENDOR.md can say the vendored files were not touched. It cannot fail. This plan records the sha256
of the PRISTINE upstream bytes of all six files in a committed manifest, together with the exact
inverse of each permitted delta, and adds a spec that reconstructs the pristine bytes from the
vendored file and compares hashes. Any fourth change moves the hash.

The manifest is 1 KB. A committed pristine copy of all six files would be ~436 KB duplicated in the
repository and in every per-deploy GPLv3 source archive, and would assert exactly the same property.

Purpose: FOUND-02, ROADMAP criterion 2 (every vendored file names its BOTOR origin, and a written
sync procedure documents how to re-pull against a recorded upstream SHA).
Output: one read-only recording script, one manifest, one spec with 14 tests.
</objective>

Reconstruction algorithm, per file:

1. `readFileSync(root(entry.vendored))` as a Buffer. Decode with `"utf8"` (`pad.test.js` contains
   non-ASCII; UTF-8 round-trips it losslessly, and step 5 proves the round trip was lossless).
2. Split on `"\n"`. Find the index of the first line equal to `manifest.headerSentinel`. Assert it
   is found and that its index is `< 12` - a sentinel appearing deep in the file means the header
   was not written as specified.
3. Assert the line immediately after the sentinel is the empty string, then drop lines
   `0 .. sentinelIndex + 1` inclusive and rejoin with `"\n"`.
4. For each delta in `entry.deltas`: assert the vendored text occurs EXACTLY once
   (`body.split(d.vendored).length - 1 === 1`, with a message naming the file and the text), then
   replace that single occurrence with the upstream text.
5. `const buf = Buffer.from(body, "utf8")`. Assert `buf.length === entry.bytes` BEFORE hashing - a
   length mismatch is a far more readable failure than a hash mismatch, and it catches a lossy
   decode.
6. Assert `createHash("sha256").update(buf).digest("hex") === entry.sha256`.
