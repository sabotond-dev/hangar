<interfaces>
Facts this plan is built on, all measured:

- `prerender.entries: ["*"]` in `vite.config.ts` prerenders `/dev/fidelity/` with no link from
  anywhere and no entry-list edit. `build/dev/fidelity/index.html` appears, containing the
  pre-mount text.
- `src/routes/+layout.ts` sets `trailingSlash = "always"`, so the e2e must navigate to
  `/dev/fidelity/` with the slash. Without it the static build 404s.
- The WASM work must happen in `onMount` behind a dynamic `import`. At module scope the SERVER build
  also imports grid-protocol, resolves `@wasm-fmt/lua_fmt` through its `"node"` condition and reads
  the wasm off disk during prerender. Harmless, but it proves nothing about a browser.
- `playwright.config.ts` runs `npm run preview` (= `npm run build && wrangler dev --port 4173 --ip
  127.0.0.1`) as its `webServer`, with `reuseExistingServer: !process.env.CI`. That flag is exactly
  why the stale-tree preflight matters: Playwright will happily attach to a zombie.
- `worker/index.js` sets `Cache-Control: private, no-store`, `X-Robots-Tag: noindex, nofollow,
  noarchive` and `Referrer-Policy: no-referrer` on every asset, and no CSP. If a CSP is ever added
  (a reasonable Phase 6/7 hardening for a page that talks to hardware), `script-src` MUST include
  `'wasm-unsafe-eval'` or this breaks with a symptom identical to "the formatter never initialised".
- `@wasm-fmt/lua_fmt`'s `__wbg_load` falls back to `WebAssembly.instantiate` with a console warning
  when the MIME is wrong, so a MIME regression degrades silently rather than breaking. That is why
  the e2e asserts the response `content-type`.

HANGAR's pad surface, from plan 05 (`src/lib/pad/index.ts`):
`compilePreset(id)`, `costOf(result)`, `measureLua(lua)`, `padReady()`.

Two known fragilities in this plan, both cheap to check and expensive to debug blind:

- `$lib/pad` resolves to `src/lib/pad/index.ts` by directory-index resolution. If Vite or Kit ever
  stops resolving a bare directory under `$lib`, the probe page fails at `await import` and the
  symptom looks exactly like a WASM failure. If the probe reports `error: Failed to resolve...`,
  import `$lib/pad/index` explicitly rather than debugging the formatter.
- The e2e gate greps the captured log for the word `failed`, so no Playwright test title in this
  repository may contain it. The two titles in this spec do not; keep it that way when adding more.

The `/dev/fidelity` route ships in every deploy. It is behind Basic Auth until the embargo date and
the Worker sends `X-Robots-Tag: noindex` on everything; after the gate is removed it becomes a
publicly reachable unlinked page that exposes nothing. That is the accepted outcome - revisiting it
at launch is a deferred idea, noted in `docs/DEPLOY.md`'s launch checklist, not a gate on this phase.

```svelte
<!--
  D-12: the production-build WASM proof.

  This page is prerendered (prerender.entries: ["*"] in vite.config.ts) and
  linked from nowhere. Its only job is to run the vendored compiler in a real
  browser against the real static build, so that e2e/fidelity.e2e.ts can prove

  initialises under whatever headers the deployed site actually sends.

  The imports are DYNAMIC and inside onMount on purpose. At module scope the
  server build would also import grid-protocol, resolve @wasm-fmt/lua_fmt
  through its "node" export condition and read the wasm off disk during
  prerender - harmless, and completely meaningless as a browser proof.

  Copyright (C) 2026 Botond Sandor. Licensed under the GNU GPL v3 or later.
-->
<script lang="ts">
  import { onMount } from "svelte";

  let out = $state("pending");

  onMount(async () => {
    try {
      const { compilePreset, costOf, measureLua } = await import("$lib/pad");
      const built = await compilePreset("aurora");
      const c = await costOf(built);
      out = JSON.stringify({
        preset: "aurora",
        setupRawLength: built.setupLua.length,
        timerRawLength: built.timerLua.length,
        setupCompressedLength: await measureLua(built.setupLua),
        timerCompressedLength: await measureLua(built.timerLua),
        costSetupUsed: c.setup.used,
        costTimerUsed: c.timer.used,
      });
    } catch (error) {
      out = `error: ${error instanceof Error ? error.message : String(error)}`;
    }
  });
</script>

<h1>Fidelity probe</h1>
<p data-testid="fidelity-probe">{out}</p>
```

```ts
import { readFileSync } from "node:fs";
import { expect, test } from "@playwright/test";

const baseline = JSON.parse(
  readFileSync(
    new URL("../src/lib/fidelity/preset-baseline.json", import.meta.url),
    "utf8",
  ),
);
const aurora = baseline.presets.aurora;

test.describe("the Lua formatter WASM resolves from the production build", () => {
  test("the hidden probe compiles aurora in a real browser against build/", async ({ page }) => {
    const wasm: { url: string; status: number; type: string | null }[] = [];
    const consoleErrors: string[] = [];
    page.on("response", (r) => {
      if (r.url().endsWith(".wasm")) {
        wasm.push({
          url: r.url(),
          status: r.status(),
          type: r.headers()["content-type"] ?? null,
        });
      }
    });
    page.on("console", (m) => {
      if (m.type() === "error") consoleErrors.push(m.text());
    });

    // trailingSlash: "always" (+layout.ts). Without the slash the static build
    // 404s and the failure looks like a broken route rather than a URL typo.
    await page.goto("/dev/fidelity/");
    const probe = page.getByTestId("fidelity-probe");
    // 628 KB of WASM over a cold wrangler; measured 833 ms including page load,
    // but the budget is generous because a timeout here should mean "it never
    // initialised", not "the machine was busy".
    await expect(probe).not.toHaveText("pending", { timeout: 30_000 });

    const out = JSON.parse((await probe.innerText()).trim());
    expect(out).toEqual({
      preset: "aurora",
      setupRawLength: aurora.setupRawLength,
      timerRawLength: aurora.timerRawLength,
      setupCompressedLength: aurora.setupCompressedLength,
      timerCompressedLength: aurora.timerCompressedLength,
      costSetupUsed: aurora.costSetupUsed,
      costTimerUsed: aurora.costTimerUsed,
    });

    expect(wasm.length, "no .wasm response was observed").toBeGreaterThan(0);
    expect(wasm[0].status).toBe(200);
    // A wrong MIME does not break the formatter: lua_fmt falls back from
    // instantiateStreaming to WebAssembly.instantiate with a console warning.
    // It just gets slower, silently, forever. So assert it.
    expect(wasm[0].type).toBe("application/wasm");
    expect(consoleErrors).toEqual([]);
  });

  test("the probe page is not linked from the site", async ({ page }) => {
    await page.goto("/");
    expect(await page.locator('a[href*="/dev/"]').count()).toBe(0);
  });
});
```
